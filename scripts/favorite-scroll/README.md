# 收藏自动翻页（纯翻页版）

2026-09-29，按用户要求精简。

## 使用

双击本文件夹内的“启动收藏自动翻页”快捷方式，打开专用浏览器。进入自己的“收藏 → 视频”列表，点击面板上的“开始”。工具会自动定位列表并连续向下滚动。

面板只保留：

- 开始
- 暂停
- 速度：舒缓 / 快速 / 更快（默认快速）

不需要点击作品来选择区域。运行时拦住面板外的点击，避免误打开作品；点“暂停”后即可正常操作网页。

到达当前已加载内容的底部时等待加载。底部持续 60 秒没有变化，工具自动暂停，页面保持在当前位置，供你比对最后一个作品。若只是网络慢或仍在加载，可以再次点“开始”。“底部暂时不动”并不等于平台明确确认全部读完。

请保持标签页可见。切换页面或出现登录、验证提示时会暂停；需要用户自己完成验证。关闭专用浏览器即可结束。

## 已移除

已移除收藏接口监听、响应正文抓取、作品 ID 计数、JSON 报告、资源监测、轻量模式、图片拦截和后台计数逻辑。图片和视频由抖音网页照常加载，便于直接查看最后一个作品。

不再创建或更新“收藏网页翻页记录”。之前的记录、登录会话和历史排查说明保留，没有清理用户数据。软件内的“读取结果报告”仍是之前确认的待办，不属于这个纯翻页工具。

网页本身仍可能卡顿或崩溃；本次精简不能保证 Chrome 永不崩溃。末尾作品相同也不能单独证明中间完全没有遗漏。
