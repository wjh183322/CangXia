# 收藏自动翻页（纯翻页版）

2026-09-29，按用户要求精简。

## 使用

双击本文件夹内的“启动收藏自动翻页”快捷方式，打开专用浏览器。进入自己的“收藏 → 视频”列表，点击面板上的“开始”。工具会自动定位列表并连续向下滚动。

面板只保留：

- 开始
- 暂停
- 速度：舒缓 / 快速 / 更快（默认快速）

不需要点击作品来选择区域。运行时拦住面板外的点击，避免误打开作品；点“暂停”后即可正常操作网页。

到达当前已加载内容的底部时等待加载。底部持续 60 秒没有变化，工具自动暂停，页面保持在当前位置，供你比对最后一个作品。若只是网络慢或仍在加载，可以再次点“开始”。“底部暂时不动”并不等于平台明确确认全部读完。

请保持标签页可见。切换页面或出现登录、验证提示时会暂停；需要用户自己完成验证。关闭专用浏览器即可结束。

## 长列表滚动卡顿调整（2026-09-29）

只调整滚动与渲染，不恢复计数、报告、接口抓取或资源监控：

- 滚动更新最多约每秒 30 次，列表尺寸约每 250ms 读取一次，避免每帧反复计算长列表布局。
- 页面明显掉帧时短暂让出时间，不追赶补滚一大段距离。
- 对收藏卡片使用 content-visibility:auto 和保留高度的 contain-intrinsic-block-size，离屏卡片由浏览器按需绘制。卡片不删除，顺序不变；屏幕内和最后的作品正常显示。
- 新出现的卡片同样处理，批量读取样式后统一写入，避免交替读写触发布局。停止工具时可还原工具修改的样式。

参考：[Chrome 团队关于离屏内容渲染的说明](https://web.dev/articles/content-visibility)。此方法减少渲染工作，不会清除抖音自身保留的全部作品数据，也不能保证浏览器不再崩溃。

验证：隔离的真实 Chromium 页面放置 5000 张模拟卡片，优化前后列表高度相同、最后作品可见、追加卡片生效、移除工具后样式恢复；模拟 120Hz 动画回调时一秒只读取 8 次尺寸属性（4 组高度/视口）。真实抖音页面短时滚动检查通过，但两万条长期运行尚未验证完成，不能宣称彻底解决原生崩溃。
