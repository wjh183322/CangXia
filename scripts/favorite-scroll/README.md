# 收藏网页自动翻页

独立辅助脚本，2026-09-28。它操作抖音正常网页列表，不调用藏匣收藏读取接口，不代替软件内待开发的“读取结果报告”。

## 启动

桌面 `收藏自动翻页工具` 文件夹内双击 `启动收藏自动翻页.cmd`。

首次使用会打开一个独立 Chrome/Edge 窗口，需要在抖音正常登录。它不会自动导入藏匣或日常浏览器的登录信息。

1. 在这个窗口登录抖音，打开自己的**总收藏作品列表**。
2. 右侧“收藏网页自动翻页”面板点击“选取列表”，再点击收藏卡片或列表空白处。这一步只选取滚动区域，不会打开作品。
3. 点击“开始自动翻页”。默认每 3.5 秒滚动约四分之三屏，可改为 6 秒或 10 秒。
4. 不要在运行时切换账号、自建收藏夹或页面。保持这个标签页打开；电脑休眠或浏览器冻结会中断执行。
5. 可点“暂停”。遇到验证需要用户自行完成；脚本不会填写验证码或自动反复重试请求。
6. 首屏已经显示作品，即可选取列表并开始，无需先捕获第一页接口。若未捕获完整分页链，会明确标为观察数，不能当成确定总数。

脚本会正常保留专用浏览器的网站会话；不要把浏览器资料目录作为报告上传。

## 如何判断结果

- 面板“至少见到”是页面作品链接 ID 与已捕获接口 ID 的去重并集，表示观察到的数量，不保证覆盖全部收藏。
- 第二行单独显示接口已记录作品/页数；没有捕获响应时显示“仅页面观察”。两种来源不能直接相加。
- 只有从 cursor=0 开始连续连接到明确 has_more=false/0，才记录 `serverEnd: true`。中间缺页、游标循环不算完成。
- 连续两分钟没有新的页面进展会暂停，**不宣布全部读完**。看到这个提示要检查是否选错滚动区域、网络慢、网页要求验证等。
- 一页响应变化、非 200、列表结构异常等会暂停并记录原因。
- 即使服务器明确返回末页，也只能证明当前网页返回的可访问列表已到末尾，不能证明失效/隐藏的历史收藏都被返回。
- 不建议与藏匣“全部读取”同时运行。分开完成后比较两边数量和首尾作品，必要时再比较作品 ID。

## 保存位置

观察记录：当前 Windows 用户桌面的 `收藏网页翻页记录` 文件夹。每页返回及状态变化时自动写入，运行中也至少每 15 秒更新一次。

JSON 包含作品 ID、简短标题、公开作品链接、分页位置、数量、结束状态、停止原因。schemaVersion=2 中 pages 为页数，pageRecords 为分页明细，observedIds 为观察 ID 并集。不要仅凭文件名或滚动停止就判断完成，应检查 `hasFirstPage`、`continuousPages`、`serverEnd` 和 `reason`。

不记录 Cookie、请求头、验证码或带鉴权的媒体地址。网页加载缩略图是抖音自身行为，脚本不额外下载原视频/图片，也不点赞、收藏、取消收藏或删除内容。

浏览器会话目录：`%LOCALAPPDATA%\CangXia-FavoriteScroll`。

关闭该专用浏览器标签页/窗口，或者在启动窗口按 Ctrl+C 即可结束。已写入的记录保留。网页刷新后原有已加载卡片是否保留由抖音决定；脚本不会把上次文件中的游标拿去直接请求接口续读。

## 环境与当前验证边界

需要 Node.js 24+ 和 Chrome 或 Edge，当前开发电脑已经具备。工具目录附带所需 `ws` 依赖及本项目浏览器辅助模块，复制到另一台电脑时应复制整个工具目录，并安装 Node.js 24+。

已通过合成分页和 DOM 测试：准确保留大整数 ID、重复页去重、缺页不报完成、虚拟列表移除卡片后保留观察数、明确末页停止、停滞与页面变化暂停。

真实两万条长列表的自动滚动表现尚待用户登录后实测；抖音可能调整页面结构、分页接口或权限，脚本遇到无法确认的情况会停止而不是给出虚假的完整结果。

## 2026-09-28 修复首屏阻塞

移除“必须先捕获 API 第一页才能开始”的条件；支持首屏/缓存已经渲染时直接滚动。接口统计与 DOM 观察明确区分，补充 JSON 请求体游标解析，以及不含参数/凭据的接口路径诊断。仍不把缺少完整分页链的结果标为已读全。

实际排查确认：当前抖音网页向 `https://www-hj.douyin.com/aweme/v1/web/aweme/listcollection/` 发送 POST 收藏请求。旧脚本只监听 `www.douyin.com`，因此漏掉响应。观察器现兼容两个明确地址，并忽略 OPTIONS 预检；没有新增主动接口请求。

9 项相关单元/DOM 测试通过，修复文件已同步到桌面工具目录。修复后重启操作被自动审批拦截（仅返回 blocked by policy），因此修复后的真实持续翻页尚未验证；需要用户双击启动文件，再选取收藏列表并开始。原浏览器登录资料保留，无需清缓存。
