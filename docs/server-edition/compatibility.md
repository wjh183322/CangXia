# 藏匣备份版 0.3.46 与服务版 0.4.1 入口对照

基线为 `08e6436522a3828211e9c32b51f90d7d830b4fa8`。逐项核对该提交的 `src/`、`electron/preload.cjs` 和 `electron/main.mjs`。`product-identity.test.mjs` 载入旧 preload，检查它实际发出的调用、状态分块及三个事件，对照主进程直接注册和两组循环注册，并比对页面调用与下表。页面经变量选取的操作（删除、单独下载、作者），以及本身无 IPC 的交互，按原控件核对。

下表记录已确认的目标行为与验收场景。任务编号对应[完整版实施计划](../superpowers/plans/2026-11-26-full-server-edition.md)，实际运行证据按各任务记录。

正式 Windows 处理器、已退役操作及仍待迁移验收的分支见[任务 12 运行时对照](compatibility-runtime.md)。
