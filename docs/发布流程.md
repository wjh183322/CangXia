# 备份版发布约定

备份版仅在 `codex/backup` 开发，直接以 `v0.1.7` 本地版为基点。本地版和 NAS 版分支分别维护，历史标签不改写。

1. 更新备份版 `package.json`、锁文件、设置页版本与版本说明；标题栏由构建自动生成。
2. 运行数据、组件、布局和 `test:backup-desktop` 检查，确认启动只读、服务连接、同步及退出提示。
3. 在 GitHub Actions 构建 NAS 服务 Docker 镜像并做容器 HTTPS 健康检查；下载对应产物，核对代码和校验值。
4. 构建电脑端；核对标题栏、设置页与文件名中的备份版版本一致，程序包不得包含账号会话、数据库或测试资料。
5. 把电脑端 EXE、服务镜像 TAR.GZ 和部署 ZIP 放到 `release/backup`，编写 `docs/releases/backup-vX.Y.Z.md`。
6. 提交代码并创建 `backup-vX.Y.Z` 标签，再运行 `scripts/publish-release.ps1`。

发布脚本先创建预览版草稿，检查每个附件的大小及 SHA256 后才公开。已存在的版本不会覆盖。备份版发布不改变原本地/NAS 稳定版的 Latest 标记。

软件、服务分别有版本号；协议兼容时，电脑端更新可继续使用原服务镜像。服务版本变化时需要同步更新 Compose 镜像标签。
