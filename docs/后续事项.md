# 后续事项

## 已延期：独立备份

用户决定先继续 NAS 媒体库开发，待新增硬盘后再配置备份。此项不阻塞当前开发。

- 确定要备份的媒体、收藏记录、标签、排序和下载历史范围。
- 根据实际数据量、增长量和保留版本数确定新盘容量；预留空间，不能把备份盘剩余空间全部计作已受保护的新数据容量。
- 配置定期备份，并实际恢复文件和媒体库记录进行检查。
- RAID1、NAS 回收站和藏匣的删除归档分别解决不同问题，不能替代独立备份。

## NAS 模式后续验证

- 在第二台实体 Windows 电脑上完成接力使用、凭据与播放验收。
- 在实际外网断线、NAS 重启和大文件传输条件下观察恢复体验。
