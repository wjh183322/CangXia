# 藏匣备份版 0.3.25

账号收藏和作者作品的批量下载先显示实际范围：未保存到本机、已完整保存、可补齐及待检查的数量。默认选择“只下载未保存”的作品，完整作品不再重新加入普通下载队列；需要补齐时可另选“下载并补齐”。提交时重新计算范围，避免确认期间状态变化导致重复入队。

对旧版本已经误加入的普通任务，确认“只下载未保存”时，会移除本次所选作品中无需下载的旧普通任务。仅影响这些未完成的普通任务，已有本地文件、收藏记录、NAS 副本和完成历史保留；未选择的任务、NAS 恢复任务及高清图任务保留。

新增下载状态筛选“未保存到本机”，可以先筛选后全选结果。它与“待下载 / 待补齐”分开：已经保存过媒体但文件缺失、状态未确认的作品不计入此筛选。状态待确认的已保存作品不自动按缺失重新下载，待文件检查完成后再补齐。

批量分类使用现有轻量作品索引与文件状态，不在主线程逐条检查磁盘。NAS 页面仍明确从 NAS 恢复；单独下载的独立目录行为不变。

验证覆盖混合选择、未保存筛选、失效文件与未确认文件、旧任务清理的数据保留，以及三万条选择的分类。界面验证覆盖范围确认、提交失败保留选择和成功后清除勾选；真实桌面 IPC 验证确认只加入新增作品，旧媒体文件的修改时间保持不变。

退出旧客户端后覆盖安装即可，NAS 服务仍使用 0.2.2。处理已有误入队任务时，可先暂停下载，再全选需要处理的收藏列表，点击“下载所选作品”并确认“只下载未保存”；没有新作品时，按钮显示“移除无需下载的旧任务”。无需清空资料或重新读取作品。
