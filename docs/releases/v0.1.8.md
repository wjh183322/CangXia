# CangXia v0.1.8 — NAS 媒体库预览版

Windows 10/11 64 位免安装程序：`CangXia-0.1.8-Windows-x64.exe`。

本版加入 NAS 模式，供已连接 SMB 共享文件夹的用户验收。稳定版 v0.1.7 保留。

- 设置中先预览迁移范围、有效文件大小和目标容量，再复制、校验并切换。本机原库和文件保留；目标已有库时拒绝合并覆盖。
- 在另一台电脑选择“打开已有 NAS 库”。共享作品信息、收藏夹关系与顺序、标签、下载记录；抖音登录凭据、缓存和窗口设置仍在每台电脑本地。
- Windows 文件句柄保持单写入者锁。第二客户端只读，显式重新连接后尝试取得写入权；修改后的元数据通过同一个锁句柄确认提交。
- 元数据使用校验过的不可变版本文件和相对媒体路径。下载先在本机暂存，再复制到 NAS 并检查 SHA256。断线后停用修改，未确认的本机副本不会自动覆盖服务器记录。
- 删除作品前完成可恢复副本，再提交删除；在设置里恢复已删除作品。旧版本和删除归档会占用 NAS 容量，本版不自动清理。
- 用户已将独立备份延期，记录在[后续事项](../后续事项.md)，不阻塞 NAS 开发。

## 使用

1. 在 Windows 资源管理器确认共享文件夹可打开、读写。共享凭据由 Windows 管理，藏匣不保存 NAS 密码。
2. 进入“设置 → 迁移本机库到 NAS”，选择共享文件夹，检查预览并确认。完成后可在设置看到当前电脑可写。
3. 换电脑前退出当前藏匣；另一台选择“打开已有 NAS 库”，并按需重新登录同一个抖音账号。
4. 断线后重新连接。如果出现恢复副本提示，可打开本机恢复目录保留待处理修改；本版不提供未提交元数据的自动合并。
5. 返回本机库会显示迁移前保留的本机资料，不会把 NAS 后续修改自动同步回来。

## 验证与边界

- 58 项自动化数据测试通过，包含真实 Windows 文件锁、双客户端交接、迁移保留、相对路径重挂载、损坏快照拒绝、截断提交记录、未确认修改保留、补齐下载及删除恢复。
- 16 项组件检查及 5 组 Electron 布局检查通过。
- 10 项真实主进程 IPC 桌面流程检查通过，涵盖迁移、标签、删除恢复及切换。
- 打包后的 ASAR 重复通过上述桌面流程和布局检查；22 个后端及前端构建文件与工作目录逐字节一致，包内未包含会话文件、数据库或测试资料。Windows 程序启动及登录隔离检查通过。
- 在真实 SMB 共享目录的独立临时文件夹内验证双客户端和文件操作。未迁移用户正式资料。
- 尚未完成两台实体电脑之间的接力、NAS 重启、长时间外网断连及大规模媒体迁移验收，因此作为预览版发布。

NAS 离线时列表来自本机缓存，播放 NAS 媒体仍需连接。版本文件和删除归档均在同一个 NAS 上，不能替代独立备份。真实抖音账号的分页、资源质量及平台访问限制的验证边界与上一版相同。
