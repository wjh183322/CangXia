# 藏匣备份版 0.1.0 预览

本地版、NAS 版和备份版分别在 `codex/local`、`codex/nas`、`codex/backup` 开发。本地版基于 v0.1.7，NAS 版保留 v0.1.11；备份版使用独立程序名、数据目录和版本标签。

## 本版能力

- 本机数据库和媒体作为日常工作副本，NAS 同步在后台执行。
- 启动强制比对服务状态，无法连接或未取得写入权时只读；断线保留本机未同步修改。
- 默认每 5 分钟、下载批次结束或手动触发同步。退出前提示未同步内容。
- 记录按变化同步，媒体按 SHA256 去重、分块续传；NAS 服务在本机校验，不把整个文件读回电脑。
- 显示当前同步状态、上次同步时间和提交电脑；区分记录最新与媒体已在本机。
- 多电脑交接使用租约与提交基础状态校验。双边修改不会静默覆盖；提交确认丢失可以查询恢复，避免重复提交。
- HTTPS 指纹验证先于发送访问密钥；电脑上的密钥由 Windows 加密保存。
- 可以复制导入旧版资料，原记录和原文件保留；清理本机媒体保留 NAS 备份。

## 验证

67 项数据测试、16 项组件检查通过。隔离的桌面测试覆盖启动只读、HTTPS 连接、导入预览、复制导入、后台同步、本机清理后 NAS 保留、从 NAS 恢复、标签修改及退出提示。

服务镜像通过真实 Docker 容器 HTTPS 健康检查。没有自动部署到用户 NAS，也没有迁移用户正式资料。

## 首版边界

- 需要先部署配套服务并允许指定电脑经 Tailscale 访问 TCP 18443；旧 SMB 项目可继续保留。
- 当前支持交替使用电脑，双边改动需要明确处理；不提供自动字段合并。
- 关闭软件后不继续自动同步。使用另一台电脑前应确认前一台已同步完成。
- NAS 已有的历史对象和残留上传不自动清理；容量管理和历史版本恢复界面为后续工作。
- 本机缓存与 NAS 文件不会自动相互删除；“已同步”表示当前记录及待备份内容的状态，不表示所有 NAS 媒体都已下载到本机。
- 服务实际部署后的外网速度、NAS 重启及两台实体电脑长期接力仍需现场验收。
