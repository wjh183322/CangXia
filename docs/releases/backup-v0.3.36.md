# 藏匣备份版 0.3.36

本版配套 **NAS 0.2.4**。先备份原 data 并更新 NAS，再将使用这份资料的电脑升级到 0.3.36。原目录、库 ID、密钥和证书继续使用，**无需清缓存、清资料或重读收藏**。

## 变化

- 删除分别选择读取记录/作品文件、仅本机/本机与 NAS。记录默认当前来源，账号含自建关联，其他作者来源保留。
- 仅本机移除后同步不自动补回，独立 NAS 目录可检索仅记录和媒体，分别恢复来源或文件。
- NAS 删除后其他电脑保留对应内容，集中显示电脑、时间和范围，明确选择保留并上传、删除本机或稍后处理，不再自动回传旧副本。
- NAS-only 入口保留本机副本；重新上传可在 NAS 删除待处理中勾选“包含本机删除后保留的副本”。
- 分批、可停止，先 NAS 回执后本机；路径变化、共用目录、回收站失败不假报成功，重启不自动继续删除。
- NAS 目录来源/关键词/内容/本机状态先筛选后分页，每页 20 个；具体收藏夹、作者使用各自读取顺序。
- 原图视频按需预览与 Range 读取；封面复用有界缓存，NAS 配乐使用其对应版本，避免混入本机另一音轨。
- 操作正文默认 90 天/50 MiB，未解决项与防回传版本保留；旧回执不重删，长恢复授权续期。
- 修复没有实际本机改动时，旧“待同步”标记可能误报冲突；真实双端变化和未确认提交继续保护。

## 更新

1. 暂停各电脑任务并退出，停止旧 NAS 容器，保存整个原 data 副本。
2. 导入 CangXia-Backup-Server-0.2.4.tar，仅将镜像改为 cangxia-backup-server:0.2.4，保留挂载、端口、环境和网络。
3. 安装 CangXia-Backup-0.3.36-Setup-x64.exe，或使用 CangXia-Backup-0.3.36-Windows-x64.exe。
4. 用原连接重新检查。新旧写入协议不混用，尚未配套升级时仅浏览原本机内容。

NAS 自动建立迁移前一致性数据库副本。回退必须使用整个旧 data 和匹配版本，不能直接让旧镜像打开新库。见[服务说明](../../backup-server/README.md)。
