# 藏匣备份版 0.3.27

账号收藏、自建收藏夹和作者作品读取结束后自动显示读取总结，区分本轮取得、前面新增、补齐记录、已有记录返回及首次读入。到当前可访问列表末页时，还显示历史中本轮未返回的数量和累计保留记录数；提前匹配、数量限制或停止时明确说明历史尚未全量核对。

按读取位置分类：新取得的未知作品在第一条历史记录前，归为前面新增；遇到历史记录后，归为补齐记录。历史作品上一轮暂未返回、本轮重新返回时，也列入补齐并单独标注。分类描述读取位置，不推断作品是否刚发布或刚收藏。补齐记录不自动下载媒体。

完整核对保留未返回的旧记录，按已有记录的相邻位置合并本轮新记录。返回数明显下降时保留原可靠对照，不再提供确认后移除旧记录的入口。作者读取保留原来的限定数量与暂停续读，两类来源的记录和对照相互独立。

新增左侧“读取日志”入口，可以查看本机保存的全部读取轮次及其差异作品，按前面新增／补齐记录分类，打开当前藏匣作品详情或抖音作品。每轮日志与差异详情均按 50 条分页加载。首次建库只存总结，已有对照的轮次仅存差异作品的 ID、短标题、发布作者基本信息、类型、位置和取得时间；不复制封面、视频、签名媒体地址或完整作品数据。

日志默认全部保留，不自动裁剪，也不自动同步到 NAS。界面显示日志文本大小（不含索引、空闲页及当前读取对照）；支持确认后清空本机日志，作品、媒体、NAS 副本与读取对照保留。清理后空间供 SQLite 复用，不执行整库压缩。升级只能导入旧版现存的最近读取摘要，无法补回旧版未保存的全部历史和差异详情。

验证覆盖前面新增、中间补齐、历史重新返回、未返回记录保留、暂停／重启／续读、事务回滚、收藏与作者隔离、分页及仅清理日志。使用用户提供的 A、B 作品 ID 与顺序进行隔离数据模型重放，得到前面新增 0、补齐 14、未返回 34、累计保留 29,678，差异日志仅 14 条。此重放不连接抖音，不改用户原库，不代表已在遵义完成一轮新版真实读取。

退出旧版后覆盖安装即可，NAS 服务仍使用 0.2.2。以后直接保留资料进行完整核对，无需为比较结果清空库。
