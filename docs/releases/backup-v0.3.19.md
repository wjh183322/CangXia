# 藏匣备份版 0.3.19

“更新作者信息”改为仅手动触发。打开、重复进入作品详情，或登录和 NAS 状态变化，都不会自动查询作者主页或刷新作品作者信息。只有点击详情中的“更新作者信息”才更新该作品，仍支持停止更新和缓存展示。

正常读取收藏、作者作品时继续使用 0.3.18 修正后的网页参数，并保存接口返回的发布作者、抖音号和共创关系。重新读取有助于取得这些字段，但如果平台当次没有返回完整信息，仍可能缺失，保留手动更新入口供按需补充。

退出旧客户端后覆盖安装 0.3.19，无需卸载。NAS 服务继续使用 0.2.2，无需重新部署。本次更新不清理本地资料或 NAS 数据。

验证覆盖已登录且 NAS 可写时打开缺失信息的作品、反复进入详情、状态变化均不发起更新请求；手动按钮才触发更新，旧请求结果不会串到其他作品。
