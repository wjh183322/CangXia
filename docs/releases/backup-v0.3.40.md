# 藏匣备份版 0.3.40

作品状态核验改为仅使用接口 JSON，删除逐条打开作品网页的复核流程。视频与图文使用同一套规则，减少等待页面加载和错误提示的耗时。NAS 服务继续使用 0.2.4。

- 匹配作品 ID 的详情及视频或图片资源支持“可访问”判断。
- 已验证的权限、审核、隐私响应，以及调用成功、详情明确为空、过滤对象 ID 匹配且原因为空的组合，判断为“已失效”，含义是原作品当前不可访问，不推断永久删除。
- 缺少必要字段、作品 ID 不符、未知响应、登录验证、限流和网络异常保留“暂无法确认”，不再额外加载作品网页。
- 单条核验、检查与补齐中的批量核验，以及下载刷新资源时的失效识别共用接口判断。已失效作品跳过普通下载和补齐；读取记录、本机文件及 NAS 备份保留。
- 后续重新核验取得正常详情后恢复为可访问，不自动重启之前失败的下载任务。

专用浏览器继续用于账号登录和普通接口请求；用户手动打开抖音原作品、导入公开作品的既有功能保留。已有历史核验记录保留，不清空缓存或资料库。

本机完整测试 646 项、状态专项 61 项、源码与打包后的 JSON 浏览器检查各 21 项、后台账号读取 16 项、打包桌面集成 76 项通过。两种实际 EXE 已独立解包并启动验证；尚未将本机结果作为云端 CI 或真实用户账号验收。

后续[云端完整复核](https://github.com/wjh183322/CangXia/actions/runs/39602169897)已完成：同一源码提交的四组 Windows 测试共 646 项通过、零失败、零跳过，desktop 与 server 作业均成功。具体分组及源码提交记录在本版验收数据中。
