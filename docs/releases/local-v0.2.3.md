# 藏匣本地版 0.2.3（预览）

修复 0.2.2 将普通登录页误判为短信验证、自动展开整个抖音网页的问题。普通登录页可以同时显示二维码和验证码输入框；验证码输入框本身不再触发身份验证弹窗。

- 默认保留原来的小扫码窗口，显示提取的抖音二维码。
- 检测到明确的短信、身份或安全验证要求时，仍可自动显示官方验证页。
- 保留手动“在此窗口完成验证”和独立窗口入口。
- 窗口左上角和设置版本号同步为 0.2.3。

退出 0.2.2 后运行 `CangXia-Local-0.2.3-Windows-x64.exe`，保留原资料与下载目录，无需清空缓存。

验证使用独立测试目录和合成页面，覆盖二维码与验证码表单同时出现、二维码尚未加载、真实验证布局识别、内嵌页面隔离与会话保持。未发送真实短信；未修改用户收藏、NAS 版、备份版或 NAS 配置。请求方式与签名问题不在本次修复范围内。
