# CangXia v0.1.5 — 删除文件后可重新选择保存目录

修复 v0.1.4 按数据库下载记录锁定目录的问题：在资源管理器删除文件后，历史记录仍在，导致无法选择新目录。

- 改为检查作品目录中的实际文件。视频、图片、作品信息、损坏文件或未完成文件仍存在时继续锁定；只有空目录或文件已全部删除时允许更改。
- 打开设置自动检查文件，设置里也新增“重新检查文件”按钮。
- 成功选择新目录后，清理已不存在的旧文件位置，避免重新下载时引用旧路径。收藏列表、排序、我的标签和下载历史继续保留。
- 文件不可访问或磁盘暂时不可用时不会当作文件已经删除；读取或下载运行期间仍禁止改目录。

使用方式：打开右上角设置，点击“重新检查文件”，再点击“选择目录”。如果仍被锁定，请检查旧作品目录是否还保留图片、作品信息或未完成文件。

验证涵盖外部删除文件及整个目录、残留文件锁定、新目录重新下载，以及收藏、标签、历史保留。

发布前验证：51 项自动测试通过；在隔离的桌面测试库中验证了实际文件锁定、删除整个目录后刷新解锁、选择新目录后保留收藏和标签。

Windows 10/11 64 位免安装程序：`CangXia-0.1.5-Windows-x64.exe`。
