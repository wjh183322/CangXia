# CangXia Windows 本地版 v0.1.1 — 登录流程修正版

本系列源码分支为 `windows-local`，发布标签为 `windows-v0.1.1`，与仓库已有同号版本分开维护。

Windows 10/11 64位免安装程序。

## 本版变化

- 登录窗口明确显示“藏匣 · 抖音网页登录”，避免与官方客户端混淆。
- 登录期间不启用采集监听；未检测到网页登录状态时不发起收藏同步。
- 取消解析超时后的自动刷新。
- 遇到频率限制时暂停自动任务并退避，不自动重试。

## 使用

退出旧版藏匣，打开 `CangXia-0.1.1-Windows-x64.exe`。点击“连接抖音账号”，在标题含“藏匣 · 抖音网页登录”的窗口中正常登录。数据保存在本机，升级不需要删除媒体库或登录会话。

## 验证与限制

17项自动测试及4项原生登录隔离检查通过，打包后的启动检查通过。

此修正不能保证解除抖音当前的平台限制。真实账号的收藏和收藏夹完整分页仍需登录验收。单图已测样例仅360×640，更高清版本及与存图宝的一致性尚未验证。

附件包含免安装程序及 SHA-256 校验文件。
