# CangXia v0.1.2 — 系统浏览器登录、配置导入与预览

Windows 10/11 64位免安装程序。请先完全退出旧版藏匣，再打开本版。

## 本版变化

- 改用系统 Chrome/Edge 专用窗口登录，完成后在藏匣点击“我已登录，连接”。
- 可导入 `sujingyan12138/douyin-collection-downloader` 生成的 `config.json`，复用已成功的会话；配置仅在本机读取，凭据用 Windows 加密保存。
- 通过已连接会话读取总收藏和自建收藏夹，保留预览、单选、当前页视频全选及跨页全选。
- 增加下载前的视频预览，读取列表仍不自动下载。
- 按服务返回游标继续读取，不使用参考项目固定17页的限制。
- 比较实际静态图片像素，保存所选来源及尺寸；支持更多视频清晰度字段。

## 图片核查结论

参考项目选取视频 `cover` 的第二条图片地址，没有验证原图尺寸。对同一公开视频示例的网页详情数据实测，该地址得到440×330，另外两种静态封面均为360×640。因此本版仍不会承诺所有作品都有高清原图，也不会放大或重压缩后冒充原图。

## 验证范围

配置解析与加密存储、分页完整性、补齐下载、文件归属和选图测试通过；系统 Chrome 启动及本机 CDP 连接通过；公开视频、单图和元数据实际下载通过。个人账号的正常登录、收藏完整分页及排序仍需实际账号验收。

本版不清除旧媒体库，不更换 IP、不生成请求签名、不绕过登录或验证码，遇到平台频率限制停止自动任务。
