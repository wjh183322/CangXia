# 藏匣备份版 0.3.26

“本地媒体库 → 全部结果全选 → 检查并补齐”改为在独立后台线程检查文件，界面立即显示进度和“停止检查”。访问文件设置超时，保存目录不可用时列为无法检查，不会当作全部媒体缺失自动下载。停止检查保留已检查的结果和原有资料。

问题结果每页最多显示 50 个作品，每个作品只展示前 20 个缺失项并提示剩余数量，避免一次渲染成千上万条结果。检查结果通过令牌引用完整的后台结果；开始补齐前也在后台重新核对所有已确认缺失的作品，避免只处理当前页。确认期间仍可停止，停止后不会开始下载。

检查期间暂停新备份的自动启动，防止读取资料、删除、下载与检查相互冲突。关闭程序会停止这项只读检查。大量缺失作品加入补齐队列时，使用轻量作品索引取得名称，避免在主线程重新解析每条作品的完整数据。

验证包括：两万条检查途中主线程计时继续运行且可取消；五千条作品对实际测试文件进行检查，发现缺失文件；一万条问题结果的界面每页仅 50 条；确认补齐期间取消不产生下载任务。桌面 IPC 验证检查过程中仍能读取状态并停止。

还对之前提供的 29,666 条资料库做了只读调度压力检查：该次主线程持续响应，返回结果只包含当前页。遵义电脑的实际媒体文件不在本机，因此此项只验证大资料库调度及目录不可用处理，不代表已经验证遵义全部媒体文件，也不代表实际文件检查只需相同时间。

退出旧版本后覆盖安装即可，无需清空资料、重新读取作品或升级 NAS 0.2.2。检查结果中的完整、缺失和无法检查分开显示；只有确认补齐后才启动下载。
