# 藏匣备份版 0.3.11

高清图匹配改为独立手动功能。普通下载、从 NAS 恢复和普通文件补齐均不再自动调用高清匹配组件，下载结束后不会接着分析视频。

使用方式：

- 本地媒体库勾选作品，点击底部“补齐高清图”，检查本次可处理的视频数量后开始。
- 单个视频的作品详情中也可以点击“补齐高清图”。
- 图文作品以及没有完整本地视频的作品会被跳过，页面显示跳过数量；不会为了补封面自动下载缺失视频。
- 任务在下载管理中明确标注“高清图补齐”，可暂停、取消和重试。失败重试仍进入高清补齐，不会变成普通下载。

高清图状态与普通文件完整性分开。匹配失败不撤销已完整下载的视频状态；兼容 0.3.10 遗留的“只因高清匹配失败而标记部分完成”的记录。普通“补齐失败”不再把未经高清核对的旧视频全部纳入自动匹配。

保留原封面和视频；匹配结果继续另存，NAS 已有副本保留。尺寸和画面匹配算法沿用 0.3.10，此次未修改为整帧导出，也未修改 NAS 优先的下载来源顺序。

验证：普通下载不调用匹配、NAS 恢复不调用匹配、手动混合选择过滤、单作品补齐、高清任务失败重试、下载完成标记与高清状态分离均通过。桌面集成在普通下载和恢复期间统计到零次高清组件调用，手动批量请求只处理符合条件的视频。

退出旧版后覆盖安装。无需卸载、清空数据或更新 NAS；已有普通下载队列继续下载文件，只有此前明确提交的高清补齐任务才会继续处理高清图。
