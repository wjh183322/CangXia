# 藏匣备份版 0.1.1（预览版）

修复清空本机后重新连接 NAS，作品记录已恢复但封面全部空白的问题。本机没有媒体、没有登录抖音时，现在可以直接读取 NAS 已备份的封面或图集首图，并缓存到本机。

- NAS 封面通过现有 HTTPS 服务获取，下载完成后校验 SHA256。同一文件合并请求，最多同时获取三张。
- 另一台电脑占用写入权时，也可以只读获取封面。缓存完成后，断网仍可显示已有封面。
- 封面缓存保存在 `%APPDATA%\藏匣备份版\covers\backup`，不会把作品标记为已下载，也不会自动下载完整图集或视频。
- 重新连接或点击“刷新文件状态”后重试封面，避免一次加载失败后一直空白。
- 详情中的标题、作者和标签可直接查看；完整图集和视频仍需选择“从 NAS 下载到本机”。

## 升级

退出旧备份版，运行 `CangXia-Backup-0.1.1-Windows-x64.exe`。保留已有本机数据目录和 NAS 连接配置，进入“NAS 备份”即可加载封面，必要时点击“刷新文件状态”。

**只更新 Windows 程序。继续使用现有备份服务 0.1.0，无需重建 Docker 容器、迁移 NAS 数据或更改权限。原 NAS 版和 Tailscale 容器均无需调整。**

## 验证

使用独立测试库验证：只读电脑从 NAS 获取并校验封面、离线复用、损坏对象拒绝，以及没有本地媒体和抖音凭据时在桌面程序实际解码显示图片。未替用户清理或迁移真实资料。
