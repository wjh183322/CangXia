# 藏匣备份版 0.3.18

修复 0.3.17 点击“更新作者信息”后仍只显示发布作者的问题。作品详情请求缺少正常抖音网页携带的版本和客户端参数，接口虽然返回成功，却会省略共创字段。现在直接接口与专用浏览器请求均带上已实测的能力参数，收藏和作者列表读取也使用相同参数。

修正旧缓存判断：0.3.17 误缓存的空共创信息不再阻止重新查询，升级后打开对应详情即可按需更新。接口没有返回共创字段时会提示“共创信息暂未取得”，保留已知共创作者；只有明确返回空共创列表才清除旧关系。

已对用户提供的作品 7693112789354787251 做实际接口前后对比：原请求返回成功但没有 cooperation_info，修复后的程序请求正常返回“偷懒噜／出镜”。新增请求参数、旧缓存恢复和缺失字段保护测试，并验证实际打包程序启动。

退出旧客户端后覆盖安装 0.3.18，连接抖音，在空闲时打开该作品详情；也可点“更新作者信息”。无需重新读取全部收藏，NAS 服务 0.2.2 无需重新部署。
