# 藏匣备份版 0.3.22

修复大资料库读取完成后长时间未响应的问题。遵义资料中“雷电将军”已经保存 625 条，但旧版在收尾时对全部 29,666 个本地作品反复读取全量下载记录，界面停留在 611 条。现在只整理受影响作品，每轮建立一次目录查找表，文件操作分步异步执行，停止后保留待整理项。升级会把旧版最后一次读取的相关本地作品加入待整理清单，可在设置中手动继续，不会启动时自动移动文件。

收藏及作者反向查询增加索引。下载任务迁移为逐条保存，失败补齐直接按作品查找任务；普通状态只推送计数和正在运行的任务，下载管理按 50 条分页。暂停、取消、失败、下载来源与成功历史保留，旧 JSON 不会让已取消任务在重启后复活。取消任务仍不删除收藏、本地已保存文件或 NAS 副本。

文件状态在后台检查，界面不再逐次同步检查全库文件；可停止检查，目录不可访问时标为暂不可确认，保留资料。文件变化通过目录监控通知，并有定期后台复查。列表使用轻量索引和分块传递，完整路径、文件清单及长搜索描述按需获取；详情缓存最多 8 个作品，NAS 和本地存储统计保留。初次加载仍需建立全库轻量索引，不能据此保证所有电脑都瞬间启动。

NAS 记录分析使用持久变更记录，覆盖直接 SQL 修改、删除及事务回滚；文件状态和任务进度不会反复触发整库导出。媒体哈希逐条保存，只准备有变化或归属信息需要更新的作品。大批量 NAS 记录应用分批让出界面，保持事务及中间状态保护。原有冲突保护、写入租约、幂等回执、校验和下载来源规则保留。

搜索增加作者、共创作者、标签及状态反向索引，并使用 SQLite FTS5 加速较长子串查询。中文短词保持兼容回退，最终仍按原包含匹配核对，不改变来源顺序，也不合并同名作者。

## 验证

320 项自动测试、界面测试、桌面集成和实际封面渲染回归通过。发布流程另外核对运行模块完整性、打包程序启动及打包版本的桌面集成。

使用用户提供的 29,666 条资料隔离副本，本机测得：目录纯查找 8 项约 2.9 毫秒；任务状态摘要 199 字节，50 条任务页约 9.6 KB；轻量索引准备约 1.55 秒，期间界面事件循环可执行；全库轻量状态约 30.8 MB，旧完整状态约 127 MB；首次搜索索引构建约 4.7 秒，后续查询约 4.5 毫秒；备份分析首次计算 89,645 条记录，未变时约 24 毫秒且不重新哈希，修改一个标签约 25 毫秒，仅重新计算 4 条相关记录。

这些是 CPU、索引和数据传递测量，未对用户原始媒体执行移动，也未连接实际 NAS；实际磁盘、网络及首次迁移耗时可能不同。

退出旧客户端后覆盖安装 0.3.22，无需卸载、清空资料、重新读取或升级 NAS 0.2.2。设置中若显示待整理作品，可点“继续整理本地作品”，期间可以停止。本次没有实施封面缓存容量清理或图文配乐功能，它们仍是独立研究方案。
