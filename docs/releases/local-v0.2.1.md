# 藏匣本地版 0.2.1（预览）

修复手机扫码确认后，抖音实际要求短信身份验证，而软件仍停在二维码界面的情况。

- 识别“接收短信验证码／发送短信验证”、可见验证码输入框、滑块和验证页面；优先显示验证状态，不再只检查二维码或候选 Cookie。
- 检测到进一步验证时显示同一个原始登录页面，保持扫码会话。短信发送和验证码输入由用户在抖音页面完成，软件不自动点击发送，也不读取验证码输入内容。
- 增加“手机已确认 / 检查登录”，在同一会话中重新检查，不必刷新二维码或切到另一份浏览器会话。
- 修复尚未创建登录窗口时，“打开原登录页”没有反应的问题。
- 扫码成功、等待手机确认、账号核验、旧库归属确认分别显示；旧库关联确认不再显示成“登录未完成”。
- 专用 Chrome/Edge 作为折叠的备用入口，明确它是独立登录会话，避免混淆。

## 使用

退出旧本地版后运行 `CangXia-Local-0.2.1-Windows-x64.exe`。保留现有资料目录，继续使用 0.2.0 的增量保存和读取恢复能力。

扫码确认后，如抖音要求身份验证，在弹出的原登录页按提示操作；完成后可点击“手机已确认 / 检查登录”。若显示旧库归属确认，且当前账号确实是原来的收藏账号，点击“确认这是原账号”即可，无需再次扫码。

## 验证范围

测试覆盖短信选项、验证码字段识别（不读取字段值）、普通短信登录标签不误判、扫码确认状态、原页面复用、候选会话与二次验证的优先级、验证完成继续登录以及旧库确认状态。没有替用户发送短信、填写验证码或绕过抖音验证。真实验证方式和是否放行仍由抖音决定。
