# 藏匣备份版 0.3.35

本次先交付本机下载、问题检查与界面改进。NAS 服务继续使用 0.2.3，无需清缓存、清资料或重新读取收藏。跨电脑删除与恢复是后续配套版本的工作，本版本尚未启用。

- 修复必需文件已经保存、清单仍为部分完成时反复下载确认失败。按登记资产、普通文件及大小核实后更新状态，已确认的正常文件不重复下载。
- 现有同名视频未登记时保留原文件，新下载内容另行登记。修复会更新作品信息 JSON；可以从问题列表“导出诊断”，只导出所选作品的清单与文件状态，不包含账号凭据、签名地址或整库。
- “作品检查与补齐”默认加载保存的问题总览，手动点击“检查全部”或“检查选中”才检查文件。问题总览与本轮结果分别保存和显示；核验或补齐一部分作品不清空其余问题，重启后仍可查看。
- 文件/处理状态与原作品状态分别筛选。可访问与下载失败可以同时成立，各分类数量可能重叠，总作品数按 ID 去重。
- 正在下载、等待、失败、已失效及已下载任务的标题，以及检查列表两个标签中的标题，都可打开对应本地作品详情。关闭后返回原标签、页码和滚动位置；有效选择保留，已失效的选择清除并说明。下载继续运行。
- 本地媒体库增加文件大小升序、降序，默认收藏顺序。使用文件索引，不因排序扫描硬盘；未知大小放在最后。共享配乐、浏览缓存和未登记文件单独计量。
- 根据提供的真实样本补充识别空文字的 `status_audit_self_see`。只确认目标作品当前不可访问，不把 `status_code:0` 单独作为失效依据。

正常重开保留检查结果。明确更换、清空或回退主数据库时，重建不适用的检查缓存，不改动实际作品文件。系统时间回退不会阻止问题总览反映当前已保存的核验状态。

先暂停下载/核验并退出旧程序，再覆盖安装。无需删除缓存或本机/NAS 资料。

验证使用隔离资料库，包括三万条记录、一千条问题、停止检查、跨页选择、重启和文件确认路径。遵义电脑那几条真实作品的最终结果仍需安装后核实；持续失败时可以导出单作品诊断，无需上传整个资料库。
