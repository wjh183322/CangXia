# 藏匣本地版 0.2.2（预览）

短信、滑块等后续验证现在可以直接显示在藏匣的登录弹窗中。显示的是抖音原始验证页面，不另造验证码输入框，也不额外读取或保存验证码。

- 扫码和后续验证使用同一个沙箱页面；切换显示位置时不刷新页面，保留会话及页面内的输入状态。
- 验证页面与本机软件页面隔离，没有 Node 和藏匣 IPC 接口。
- 保留“独立窗口打开”作为显示不全时的备用方式；它也使用同一个页面，不需要另开登录会话。
- 关闭登录弹窗或主窗口时释放验证页面，避免留下隐藏登录窗口。

## 使用

退出旧本地版，运行 `CangXia-Local-0.2.2-Windows-x64.exe`，保留原资料目录。扫码后若需短信或身份验证，软件会在弹窗内显示原页面；按抖音要求操作，再点击“手机已确认 / 检查登录”。也可以手动点“在此窗口完成验证”。

如果页面显示不全，使用内嵌区下方的“独立窗口打开”；切回软件内时，已输入的页面内容仍保留。若出现旧资料账号归属确认，确认是原账号后继续，不必重新扫码。

本版只修改本地版登录窗口，不改 NAS 服务、备份数据或安全部署配置。

## 验证

使用独立测试配置和合成验证页面，在实际 Electron 桌面环境验证内嵌、权限隔离、边界检查、独立窗口切换、页面状态保留和关闭清理。测试没有发送真实短信，也没有访问用户的真实验证码；真实平台验证要求仍由抖音决定。
