# 藏匣本地版 0.2.8 预览

新增“单独下载”：选中作品后，为本批选择一个文件夹，只保存图片和视频。适合壁纸等一次性用途，普通下载功能仍独立使用。

## 使用方法

1. 在账号收藏或本地媒体库中选择作品，点击底部“单独下载”。
2. 选择本次保存目录。图文会保存全部图片；“同时下载视频封面”默认不勾选。
3. 目录不是空的时，确认后才开始。已有文件不会被覆盖：完整内容相同则跳过，不同内容加序号保存。
4. 在“下载管理 → 单独下载 · 本次运行”查看各批作品数、完成数、失败数和文件数，可以暂停、继续、重试失败或取消。

所有文件平铺保存，按选择时的列表顺序编号，如 `0001_作者_作品ID_01.jpg`、`0002_作者_作品ID.mp4`、`0002_作者_作品ID_封面.jpg`。不创建作品子文件夹，不生成作品信息 JSON，不写入普通下载历史、媒体库或已下载标记，不改变普通下载目录。

已在本地完整保存的媒体优先校验后复制，原文件保留。缺少或校验不符的文件再联网取得；重新取得资源不更新已有作品资料。普通下载与单独下载暂不同时运行，需要先暂停另一种下载。

## 暂停、退出与文件完整性

- 任务和续传信息只在内存中保留。暂停后可在本次运行中继续；退出后任务清空，不支持跨重启续传。普通下载原有的持久续传不受影响。
- 取消保留已完成的文件，并清理这批未完成片段。退出时若仍有等待、暂停或失败任务，会先询问是否取消剩余任务。
- 下载先写入本批私有临时目录，校验长度和 SHA-256 后才放到目标目录。同名冲突使用不覆盖的方式处理。
- 服务器提供可靠的长度与 ETag 时，使用已校验片段续传；不满足条件则重新下载该文件，避免拼接不同内容。这里验证传输和复制完整性，不承诺修复来源本身已经损坏的媒体。
- 目标目录中可能短暂出现 `.cangxia-flat-` 开头的临时文件夹，正常完成、取消或退出时清理。断电或强制结束进程后可能有残留，退出软件后可以删除这些临时文件夹，完整媒体不受影响。
- 退出登录时，需要联网的单独下载会先暂停；仅复制完整本地文件的批次可以继续。若之后本地源文件被移除，仍需重新登录才能联网补齐。

已验证平铺命名、封面开关、非空目录确认、同名不覆盖、相同内容跳过、本地复制、部分失败与重试、内存续传、取消及退出清理，以及普通下载与登录读取的回归。实际 Electron 窗口和打包后的程序均使用隔离测试目录与合成媒体验证；未对真实账号发起批量下载。

升级前退出旧版本，再启动本版本即可。标题栏和设置版本统一为 0.2.8。此版本仅更新本地版，不修改 NAS 版、备份版或 NAS 上的服务。
