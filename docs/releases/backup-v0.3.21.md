# 藏匣备份版 0.3.21

修复大资料库检查 NAS 时显示“无法检查 / Invalid string length”的问题。旧版将变化记录和待备份记录重复放进一次性 JSON 字符串；作品信息较多时会超过 JavaScript 字符串长度限制，导致检查失败。

状态检查现在只返回变化数量、待备份封面数量和待同步记录数量。实际同步准备只传一份记录，并以有接收确认的分批消息传递记录和哈希，避免一次性拼接整个资料库。原有同步比对、冲突保护和备份提交规则保留。

使用用户提供的遵义资料副本复现旧错误并验证修复：29,952 条作品、61,908 条同步记录通过检查、准备及差异计算；用得到的哈希再次比对，差异为零。资料副本仅在隔离目录读取，没有连接或修改实际 NAS。

验证：305 项自动测试、界面与桌面集成测试；发布流程继续检查安装包内容和实际打包程序启动。

退出旧客户端后覆盖安装 0.3.21，再点击“重新检查同步状态”。无需卸载、清空本地/NAS 数据、重新读取作品或升级 NAS 服务。本次没有新增封面缓存清理功能。
