# 藏匣本地版 0.3.0 预览

2026-10-04。由作者下载试验版 0.1.5 按功能移植并适配。

本版加入作者主页链接解析、独立作者列表、批量读取和下载。收藏与作者作品按 ID 复用正常下载记录，已存在的作者下载保留原目录。普通下载和单独下载仍分别管理。

## 新增与改进

- 收藏默认“检查新增”，不再设置 500 条／20 页分段上限；连续匹配 60 个不同的历史作品且跨至少两页时停止，或到达平台明确末页后结束。
- 无可靠历史对照时，明确提示可能读完全部收藏，确认后再继续。可随时停止，已有记录和进度保留。
- 新增检查与完整核对分别保存进度；异常空列表或数量明显减少时保留旧记录，等待确认。
- 顶部、底部都可输入页码跳转，支持全角数字和输入校验。
- 提前显示启动窗口，本地列表不等待登录恢复；大库首次传输减少往返次数。
- 增加当前用户安装包，安装一次后从桌面快捷方式直接启动，避免每次解压单文件程序。

## 升级

退出同一版本系列的旧程序，运行 `CangXia-Local-0.3.0-Setup-x64.exe` 安装或覆盖升级，以后使用该版本的桌面快捷方式。无需先卸载或清缓存。原数据目录、下载目录和连接设置保留，各版本数据不会自动互相合并。

仍提供单文件免安装包，但每次运行仍有解压开销。

完整合入清单、冲突处理及验证见[核对记录](../作者试验版合入核对-2026-10-04.md)。
