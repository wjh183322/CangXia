# 藏匣备份版 0.3.46

调整取消下载、读取日志及详情删除入口。NAS 服务继续使用 0.2.4，无需升级镜像；新增计数规则保持不变。

- 单个或批量取消未完成下载，清理该任务产生的正式文件、临时片段和续传数据。保留首次创建任务前已有的文件、其他已完成任务及 NAS 备份。暂停后继续仍使用同一任务边界，暂停和网络失败保留可续传进度。
- 清理失败会显示原因并保留可重试条目。旧任务无法确认现存文件归属时会明确提示并保留文件，避免误删。文件占用等导致任务文件无法清理时会报错；目录移动仍按归属清理，被外部替换的内容保留。
- 批量读取自建收藏夹在日志中按一条显示，点进去查看各夹状态、总结和作品差异；总收藏联动读取也归入同一批次。停止和重启后保留日志，新续读不改写旧批次。
- 没有下载媒体的作品详情也提供“删除读取记录”，默认仅移除本机记录、不勾选文件；可在确认窗口选择与 NAS 一起删除。按实际账号或作者来源处理，保留其他来源记录。
- 修复 0.3.45 云端布局检查暴露的空值渲染错误，保留原失败用例作为回归。

实现边界及审查记录见[开发验证记录](../research/2026-10-22-cancel-cleanup-and-grouped-read-history.md)，测试和分发文件校验值见[版本验收](backup-v0.3.46-verification.json)。本机测试使用隔离资料与合成平台响应；云端 CI 结果单独核对。
