# 藏匣备份版 0.3.47

改善数万条记录下批量下载准备造成窗口“未响应”的问题。NAS 服务继续使用 0.2.4，无需升级镜像；读取新增计数、收藏顺序及删除范围规则保持不变。

- 批量下载确认后显示“准备下载任务”，可查看进度、停止或关闭窗口；关闭窗口不取消准备，界面入口可重新打开。
- 大库目录分析使用按需启动的只读独立进程；复用目录归属索引、分段采集原文件保护资料并持久化受理，避免逐任务反复读取全部历史清单。
- 停止准备或异常退出后，已受理任务保持暂停，未受理部分不自动创建。明确继续仅放行该批已受理任务；失败重试保留原文件保护边界。取消下载与暂停下载的清理规则不变。
- 同一批量重试或定向补齐被停止后，不会自动继续处理下一下载来源组。正在删除的作品不能重新受理，其他范围及只读浏览保留。
- 状态保存失败会显示错误并允许后续重试。部分准备失败可分页查看原因，不把失败伪装成成功数量。
- 减少运行进度导致的整库界面重建；连续搜索会取消过期筛选及大小排序，保留原顺序、分页和跨页选择。

性能数据、故障与安装包验证见[开发验证记录](../research/2026-10-28-client-responsiveness-verification.md)，审查及未覆盖的实机边界见[整分支审查](../research/2026-10-28-client-responsiveness-review.md)。测试使用隔离资料和合成响应，不代表遵义电脑、真实抖音账号或真实 NAS 的吞吐实测；不会自动安装客户端、升级 NAS 或清理现有作品。
