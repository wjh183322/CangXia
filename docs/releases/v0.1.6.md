# CangXia v0.1.6 — 收藏记录管理与紧凑界面（预览版）

Windows 10/11 64 位免安装程序：`CangXia-0.1.6-Windows-x64.exe`。

## 本次改动

- 账号收藏支持逐个勾选、本页全选和全部结果全选；有筛选时，全选只针对当前收藏夹内已经读取、符合条件的结果。
- 删除读取记录会同时从软件的总收藏和自建夹账号列表移除，不取消抖音收藏。本地文件、标签、归属、排序及下载历史继续保留。之后重新读取会恢复记录，并计入新增数量。
- 账号收藏和本地媒体库固定每页 20 个作品，顶部和底部均可翻页，翻页回到本页列表第一条。
- 压缩顶部重复说明和空白，作者、下载状态、标签和我的标签统一排列。顶部工具区固定，只有作品列表滚动，隐藏主列表滚动条；批量操作栏不再盖住封面。
- 默认窗口按主屏可用区域约 94% 宽、92% 高打开，并适配较小屏幕。
- 删除确认、目录选择和 JSON 文件选择统一为藏匣风格。目录选择支持输入完整路径、逐级浏览和新建文件夹；仅启动失败兜底仍使用系统错误提示。
- 提示消息与当前弹窗沿同一竖直中线对齐，无弹窗时相对主内容区居中。
- 本地补齐先检查视频、单图/图文图片及作品信息，显示完整、缺失和无法检查的结果。完整时不创建任务；有缺失时列出明细，用户确认后仅补齐缺失部分，并在开始前再次检查。

## 验证状态

56 项数据逻辑测试和 16 项组件交互检查通过，前端生产构建成功。组件检查使用隔离的虚构作品及临时文件，不操作真实账号或媒体库。

本次环境中的独立 Electron 运行时在加载项目代码前退出，重新解压的同版本运行时也出现相同问题，浏览器预览未能响应。因此**本版尚未完成真实桌面启动、截图和像素布局验收**，以公开预览版发布，不替换 v0.1.5 稳定版。组件交互测试不能替代实机界面验收。

账号真实大规模分页和高清单图来源的验证边界与此前版本相同。
