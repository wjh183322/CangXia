# 藏匣本地版 0.2.9 预览

选择目录窗口默认打开 Windows 实际的桌面位置，不再停在只有磁盘的起始页。保留藏匣的浅色、圆角和珊瑚红风格。

- 左侧增加桌面、下载、文档、图片、视频、音乐及磁盘入口。
- 增加后退、前进、上一级和可点击的路径导航，仍可粘贴完整路径或共享目录地址。
- 列表显示名称、修改时间和类型。单击选择文件夹，双击或按 Enter 打开；底部始终显示即将使用的目录。
- 支持搜索和新建文件夹；加载中、空目录、无搜索结果和无访问权限分别显示说明。
- 单独下载、普通下载的目录选择及登录配置文件选择使用同一套窗口。返回已选择的单独下载目录时保留该位置；首次选择默认桌面。

已通过界面与实际 Electron 桌面测试，检查了重定向桌面、目录选择、双击打开、后退导航和原有单独下载流程。标题栏和设置版本统一为 0.2.9。

退出旧版后打开新版即可，无需删除缓存或已有媒体文件。
