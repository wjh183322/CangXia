# 藏匣备份版 0.3.45

总收藏“同步收藏”窗口增加“同步自建收藏夹”勾选项。NAS 服务继续使用 0.2.4，无需升级镜像。

- 默认不勾选。勾选后，先完成总收藏，再按顺序读取藏匣已添加的自建收藏夹。
- “检查新增”和“从头完整核对”会对各夹执行相同操作；继续读取时，各夹优先使用自己的对应进度，没有可继续进度则从头执行相同模式。
- 快速读取前统一提示缺少历史对照的范围。支持停止整批并保留逐夹进度，总收藏未完成时不启动后续夹。
- 结果分别展示总收藏与各自建收藏夹，保留独立读取日志。普通单夹请求错误可以继续，登录、限流或保存进度失败会停止。
- 新增计数、已有记录、补齐及历史再次读到的判定规则保持不变。不自动下载作品。

实现与续读保护见[开发验证记录](../research/2026-10-22-total-and-custom-collection-sync.md)，本机测试和安装包校验值见[版本验收](backup-v0.3.45-verification.json)。测试使用隔离资料和合成平台响应，用户真实账号的现场结果另行核实。
