# 藏匣备份版 0.3.24

读取账号的自建收藏夹结束后，界面直接使用本次返回的最新目录，更新仍打开的“添加自建收藏夹”窗口，减少对延迟状态通知的依赖。只返回收藏夹信息，不重新加载整个作品资料库。

已从抖音目录移除的收藏夹不再留在待添加勾选中；添加时后台也会检查所选 ID，防止旧勾选重新添加已移除的收藏夹。同名、不同 ID 的真实收藏夹仍分别保留。目录读取不完整时仍保留旧记录，已保存的作品关系、本地文件及 NAS 副本不受此改动影响。

验证覆盖两个同名收藏夹、完整刷新后只剩一个、读取不完整、失效勾选清理，以及没有延迟通知时弹窗立即刷新。桌面 IPC 验证确认读取完成直接返回目录而非全库作品数据。

退出旧版本后覆盖安装即可，无需清空资料或重新读取作品。NAS 服务继续使用 0.2.2。
