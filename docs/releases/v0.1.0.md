# CangXia Windows 本地版 v0.1.0 — 初版归档

本系列源码分支为 `windows-local`，发布标签为 `windows-v0.1.0`，与仓库已有同号版本分开维护。

Windows 10/11 64位免安装程序。账号收藏与本地媒体库分开，支持收藏夹目录、封面墙、批量选择、视频和图文保存、元数据与标签筛选。
