# 藏匣备份版 0.3.34

修复“作品检查与补齐”重开或重新检查后无法筛出已保存的“暂无法确认”记录：问题列表从当前作品状态重建分类，保留视频、图片、封面等文件问题，不依赖上一轮扫描标识；没有文件缺损但原作品状态未能确认的作品也可找到并重新核验。已核验可访问且仍有文件问题的作品保持可筛选、可补齐，正常作品不额外进入问题列表。“补齐结果”保留对应任务的核验结果，不用后来保存的新状态改写旧结果。

修复核验进度混入历史失效状态：本轮进度及可访问、已失效、无法确认数量只计算本轮已完成的核验，并显示待核验数量。对于 988 条任务、205 条历史失效、实际已核验 34 条（31 条失效、3 条无法确认）的场景，显示 34 / 988、31 条失效、3 条无法确认、954 条待核验，不再显示 208 / 988。等待中的历史失效作品不会提前计入完成数；停止、继续及重开后使用已保存的实际核验结果。

验证包括该数字场景、核验前零进度、停止与恢复、任务库重开、状态筛选及历史结果分离，并在隔离原生桌面中验证重新扫描后的未知状态与完整文件保留。普通文件补齐的统计与队列行为保持原规则。

先停止核验并退出旧程序，再覆盖安装。无需清缓存、删除资料或重新读取收藏；已有核验记录与未完成任务保留。打开“作品检查与补齐”即可按已保存状态筛选，必要时点击“重新检查”。NAS 服务没有改动，继续使用 0.2.3。
