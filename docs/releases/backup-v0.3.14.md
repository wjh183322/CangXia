# 藏匣备份版 0.3.14

修复 0.3.13 安装后启动出现 `ERR_MODULE_NOT_FOUND`、找不到 `nas-removal.mjs` 的问题。原打包规则排除了所有 `electron/nas-*`，误排除了新增的 NAS 删除模块；已移除该规则。

新增发布前安装包验证：逐项核对 app.asar 中的运行文件与已测试源码一致，使用隔离资料目录启动实际打包的 Windows 程序，并通过打包后的模块运行桌面集成测试。任一项失败都会阻止发布。

退出旧程序后，直接覆盖安装 0.3.14，无需卸载，也不要删除资料目录。保留收藏、作者记录、本地文件、下载任务和 NAS 设置。

NAS 服务继续使用 0.2.1。已升级 0.2.1 的 NAS 无需再次部署；仍为 0.2.0 的服务只有使用 NAS 删除功能时才需要升级到 0.2.1。
