# 藏匣备份版 0.3.38

自动识别原作品当前是否可访问，继续配套 **NAS 0.2.4**。已更新该服务的用户只需升级电脑端，原资料、缓存和连接保留。

- 平台明确返回“由于对方隐私设置，无法查看”时，自动归为当前不可访问并保留隐私原因，不声称作品已删除。
- 返回成功但对应详情为空、原因也为空时，在已登录的专用后台浏览器中打开对应作品复核。核对作品 ID、账号会话及页面明确提示后，自动将任务归入已失效，停止该作品的抖音下载与自动补齐。
- 正常作品的对应详情和媒体资源可以确认恢复可访问，但不自动重启失败下载。登录、验证码、访问频繁、网络异常、跳转、评论或推荐文字不作为失效证据；证据不足保留暂无法确认。
- 只在需要时复核，并发为一，单次默认最多约 10 秒；可以停止。使用独立隐藏页并设置正常视口，不切换用户窗口或收藏读取页。结束后关闭临时页。
- 复核页面禁止媒体及图片传输、禁用其网络缓存，不创建正式作品下载或持久保存网页 HTML。状态仅保存简短原因、核验方式和时间。
- 已有读取记录、本机完整或部分保存的正式文件、NAS 备份均保留。已确认失效不阻止用户明确从 NAS 恢复已保存内容。
- 修复同时缓存相同封面时的重复替换竞争，复用已经校验的对象，避免 Windows 文件占用导致不必要的 NAS 回退。
- 断点续传清理自身临时文件时，对短暂 `EBUSY` / `EPERM` / `EACCES` 使用有上限的异步重试，保留下载字节校验和失败报告。

本功能自动核验使用现有正常登录和网页交互，不绕过登录、验证码或平台访问限制。真实 Chrome 与打包程序的浏览器检查使用自有隔离 profile 和合成官方页面；实际抖音页面未来变化、账号权限及访问限制仍可能导致暂无法确认。

648 项本机与 Windows 云端完整测试全部通过、零跳过；UI 165 项、原生桌面 76 项、预览 31 项及 14 项隔离浏览器检查通过。两个实际分发文件均解包并启动验证成功。详见[验收记录](https://github.com/wjh183322/CangXia/blob/codex/backup/docs/research/2026-10-21-automatic-source-verification.md)与[完整云端验证](https://github.com/wjh183322/CangXia/actions/runs/39564893670)。
