# 藏匣备份版 0.2.0 预览

本次将本地版 0.2.0 至 0.2.9 的客户端更新合入备份版，源码基点为本地版 `9b93674`。备份版仍使用独立的“藏匣备份版”配置和下载目录。

## 新功能与修复

- 大量收藏使用电脑端 SQLite 增量保存、界面差量更新和首次状态分块传输，减少整库复制。
- 读取每页保存进度；部分读取按新增作品计数，全部读取显示已检查数。读取弹窗阻止其他操作，停止后保留已读取内容，可继续有效断点。
- 恢复紧凑扫码窗口，按实际页面自动显示短信或身份验证；正常读取使用独立的后台浏览器环境，无需一直开着验证窗口。
- 登录异常显示重新登录入口，保持原收藏；核对稳定账号 ID，旧账号绑定不明时要求明确确认，不静默切换账号。
- 新增退出抖音登录；受影响的下载先暂停、保存可验证片段。退出抖音不会清除 NAS 连接信息，也不会删除备份或本机媒体。已有 NAS 备份可继续恢复，不要求重新登录抖音。
- 新增单独下载：每批选目录、媒体平铺、视频封面可选；不加入普通媒体库、下载历史或 NAS 备份记录。临时任务仅在本次运行中保留。
- 目录窗口默认桌面，增加常用位置、磁盘、前进后退、路径导航和双击打开，保留现有 UI 风格。

## 备份兼容性

备份服务仍为 **0.1.0、协议 1**。已部署的 Docker **不需要更新或重新部署**，连接地址、证书指纹及密钥沿用。

保留启动时 NAS 比对、未连通时只读、设备写入租约、冲突保留双方、NAS 封面、媒体恢复及退出前待同步提醒。读取断点、登录状态和单独下载任务不上传为共享记录；远端资料更新后会清理本机失效的旧读取断点。

## 升级

退出旧备份版后运行 `CangXia-Backup-0.2.0-Windows-x64.exe`，保留原缓存和下载目录。首次升级自动创建旧数据库的一致性副本。新版使用 WAL，运行时不要只复制主数据库文件，也不要让旧新版同时打开同一份配置目录。

附带的部署文件和服务镜像供首次部署使用；已有服务无需替换。

## 验证

通过客户端单元测试、界面测试、隔离 Electron 桌面测试及真实 Chrome 的合成接口测试。验证了旧库导入、TLS 指纹、两台客户端同步与写入租约、断线保护、NAS 媒体和封面恢复、登录验证、退出登录、读取锁定和续读、单独下载及目录选择。测试均使用临时目录和模拟数据，未操作用户实际 NAS。
