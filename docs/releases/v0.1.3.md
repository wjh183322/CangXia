# CangXia v0.1.3 — 软件内扫码弹窗

请先完全退出旧版，再打开本版。

## 本版变化

- 参考用户提供的 cangxia-legacy v0.2.6 登录方式，主入口改为软件自己的二维码弹窗，默认不再打开完整 Chrome/Edge 浏览器窗口。
- 后台读取抖音正常网页登录页的二维码图片，使用真实 Chromium 版本对应的网页模式；扫码成功后自动连接并收起弹窗。
- 二维码过期时手动刷新；需要额外验证时可打开软件内的登录验证窗口。
- 修复“登录配置含无效字段”：不再因为无关辅助 Cookie 不符合格式就拒绝有效登录，关键会话字段仍严格校验。
- JSON 配置导入移至“存储设置 → 高级”，仅作为复用其他工具登录会话的备用功能，不导入收藏、视频或图片。

## 验证与边界

用户提供安装包内的 main.mjs、login-page.mjs 和 qr.html 已与 legacy v0.2.6 标签比对一致。

真实网页取码检查通过：取得二维码图片，后台页面保持隐藏。自动测试覆盖取消登录、重复打开、无关 Cookie 异常、真正登录按钮识别与二维码提取。

这些检查不等于已经替用户完成扫码登录。实际账号登录、收藏数量与排序仍需用户确认；遇到平台频率限制会暂停，验证码由用户手动处理。原有媒体库保持保留。
