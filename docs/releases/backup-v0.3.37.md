# 藏匣备份版 0.3.37

修复 Windows 暂时拒绝替换电脑端 `backup-state.json` 时，NAS 同步及相关操作立即中断的问题。继续配套 **NAS 0.2.4**；已更新到该服务的用户只需升级电脑端，无需清缓存、清资料或重读收藏。

- 状态保存改为异步有序队列，使用独立临时文件，写入并刷新后替换；不会先删除旧状态文件。
- 短暂占用或拒绝替换时有限重试，等待期间界面可响应。持续失败保留旧文件，明确提示“本机状态保存失败”，不会假报同步完成。
- 相关 NAS 提交必须等待恢复凭据保存成功；等待期间停止后不再提交。连续保存保持先后顺序，保存期间新增的本机修改继续保留。
- NAS 已提交但电脑确认保存失败时，重启按原提交回执恢复，不重复提交；范围删除的剩余本机步骤保留，需明确重试，不重复删除 NAS。
- 退出会等待已请求的状态保存。保持现有状态文件格式、库 ID 和服务协议。

问题最初在 Windows 云端回归出现，日志为 `EPERM`。隔离测试使用真实 Windows 不允许删除共享的文件句柄复现同类替换拒绝；不能据此断定原云端占用者是杀毒软件或某个特定程序。

最终专项、完整回归、Windows 云端、安装包结果见本次验收记录。验证不修改你的真实 NAS 和资料，也不代表已逐条检查遵义电脑此前九条作品的实际文件。
