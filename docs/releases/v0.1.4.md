# CangXia v0.1.4 — 按夹读取与本地浏览

Windows 10/11 64 位免安装程序：`CangXia-0.1.4-Windows-x64.exe`。保留原来的本机媒体库与登录会话。旧项目 `cangxia-legacy` 不作修改。

## 这版修改

- 右上角新增设置齿轮。首次下载前可自定义保存目录；已有下载作品时锁定目录。
- 同步只读取当前选中的总收藏或自建收藏夹，不再遍历其他已添加夹。
- 读取弹窗默认新增 20 个，记忆修改后的数量；已有作品不计数，仍更新信息和归属。全部读取不受数量限制；可中途停止。
- 同一个作品只保留一条记录，各夹分别保存自己的顺序。从自建夹首次发现的作品也显示在总收藏的“待确认收藏顺序”分区，之后正常读取总收藏遇到它，再确定位置。部分读取保留未访问的旧记录。
- 本地封面单击进入浏览、双击打开详情，也保留显式详情按钮。视频作品先图后视频，图文按原顺序；左右切换本作品媒体，上下按照当前列表跨页切换作品，媒体边界不循环。
- 视频自动播放；全局音量在本次运行中共享，每次重新启动默认静音。浏览中打开详情时暂停视频，关闭详情后恢复浏览位置。
- 标签和我的标签独立成栏，两栏筛选取交集，栏内可选满足任意或全部。作者、下载状态和标签采用弹窗选择；点击作品标签即可筛选。
- 我的标签支持搜索、勾选已有标签进行快速标注，可一次选择多个，点击保存后生效。
- 下载管理分为正在下载、已下载。等待、暂停、失败任务保留在正在下载页；可以删除选中的完成记录或清空完成记录，不影响文件、作品归属和已下载标记。

## 验证与边界

数据逻辑自动测试覆盖当前夹请求、全局新增计数、分页结束、独立排序、待排序归位、单份文件移动、标签交集和清除历史不中断队列。隔离的桌面测试使用虚构条目及已有测试媒体，检查单击/双击、自动播放、静音及全局音量、跨页浏览、快捷标签与历史清理。

发布前结果：48 项自动测试、23 项打包界面检查与 Windows 启动检查通过；生产依赖审计未报告漏洞。打包的后端代码及前端构建文件已与本次源码构建结果逐字节核对。

未使用用户真实账号完成万条收藏的全量读取验收。“新增 20 个”可能需要检查很多已知作品，但不会因此查询其他收藏夹。部分列表显示最近成功读取的顺序，未访问内容不能保证反映平台最新变动。

图片继续保留服务实际提供的文件和尺寸，不放大像素。此次未改变高清单图获取能力；已有样例的更高清原图仍未验证。
