# 藏匣备份版 0.3.17

作品详情分别展示发布作者与共创作者，保留平台返回的共创角色，例如“出镜”。作品卡片显示共创标记。只识别平台明确返回的共创关系，不把文案中的普通 @ 提及当作共创作者。

作者名字和“筛选账号收藏”进入账号收藏总列表，按账号身份筛选，包含该账号参与共创的作品；“查看这个作者的作品”进入独立的作者作品列表。发布作者和共创作者都支持这两种入口，同名的不同账号不会混在一起。作者主页读取也支持该作者参与共创、由其他作者发布的作品。

修复作者主页已取得的抖音号未用于作品详情的问题。打开旧作品详情时，在已连接抖音、NAS 可写且没有读取或下载任务的情况下，按需更新当前作品和缺少的作者主页信息，结果缓存复用；不会重新扫描全部收藏。可手动“更新作者信息”或“停止更新”。平台暂未返回的信息会如实提示，不把内部 UID 或 0 当作抖音号。
