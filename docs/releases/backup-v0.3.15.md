# 藏匣备份版 0.3.15 / NAS 服务 0.2.2

删除 NAS 备份现在只清除当前副本，不再永久停止该作品的自动备份。本机或其他电脑仍有媒体文件时，空闲同步会重新上传；如果不想再备份，请先删除各电脑的本地媒体，再删除 NAS 备份。软件不会为了重新备份而自动从抖音下载媒体，也不会仅凭封面缓存重建已删除的副本。

保留收藏、作者资料和排序。批量删除仍可停止后续批次，共享文件继续受保护。旧版的停止备份标记会在服务升级时自动转换；本地仍有文件的作品恢复自动备份，无需逐个重新启用。移除“重新启用 NAS 备份”按钮。

此次需要同步升级 NAS 服务：导入 CangXia-Backup-Server-0.2.2.tar（无需解压），只将现有 Compose 的 image 改为 cangxia-backup-server:0.2.2，保留原 data 挂载、端口、绑定 IP 和网络，再重新部署。原密钥和证书保留。退出旧客户端后覆盖安装 0.3.15，无需卸载或删除资料；所有电脑建议统一更新。

发布前检查自动重新备份、先删本地再删 NAS、其他电脑重新上传、旧标记迁移、共享对象保护、批次取消和回执恢复。并运行打包内容检查、实际 Windows 程序启动及打包模块桌面集成测试。
