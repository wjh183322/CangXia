# CangXia v0.1.7 — 修复封面墙缩放和窗口留白

Windows 10/11 64 位免安装程序：`CangXia-0.1.7-Windows-x64.exe`。

- 修复内容区受旧 `margin: auto` 样式影响、随作品数量变化而收缩的问题。账号、本地和筛选结果使用同一宽度的内容区。
- 封面统一为 216 像素宽；单条结果、两条本地作品和完整列表保持同样大小。窗口改变时调整可容纳的列数，不缩放封面。
- 默认客户区宽度调整为 1400 像素，常规屏幕下刚好容纳五列封面及正常间距，减少原先大窗口两侧的空白。小屏幕自动限制窗口尺寸。
- 底部分页移出作品滚动区，始终保留独立位置；批量操作栏也占独立空间，不遮住封面。
- 保留 v0.1.6 的读取记录管理、每页 20 个、上下分页回顶、统一弹窗及补齐前检查。

验证：56 项数据测试、16 项组件检查通过。在真实 Electron 渲染中测量了完整列表、单条筛选结果、两条本地作品、批量操作栏和较窄窗口，封面均为 216 像素宽；分页及操作栏没有覆盖作品滚动区。另完成隔离测试库中的 23 项桌面交互检查。几何测试使用软件渲染，未验证不同显卡驱动的表现。

Windows 打包程序启动检查通过；包内后端代码与前端构建文件已逐字节核对。

```powershell
npm test
npm run test:ui
npm run test:layout
```

图片清晰度和真实账号大规模分页的验证边界不变；此版本只修复布局。下载后可通过同页 `SHA256-0.1.7.txt` 校验程序。
