# 藏匣备份版 0.3.9

普通下载新增单个取消、勾选取消和取消全部未完成任务。入口位于“下载管理 → 普通下载”：每个任务右侧有“取消”；列表上方可勾选本页、取消所选，或取消全部未完成任务。无需再次确认。

取消只停止传输并移出下载队列，涵盖正在传输、等待资源、排队、暂停和失败的任务。已完成下载历史保留；收藏、作者作品记录、NAS 副本和已保存的完整文件不删除。临时片段沿用原有中止与断点处理规则，不增加文件清理操作。

取消先持久化移出队列，再等待目标任务停止；重启不会重新排队。单个任务使用自己的中止信号，不中止其他作品的传输或资源查询。等待资源查询的任务可立即取消，不必等前面的查询完成。尚未停止的同一任务不能立即重复添加，停止后可重新选择下载。

NAS 断联、只读状态下也能取消普通下载任务。取消与“删除本地文件”完全分开。

验证：263 项自动测试、55 项界面检查、30 项桌面集成检查通过，覆盖单任务取消不影响其他任务、等待资源时取消、全部取消、持久化后重启、保留已保存图片与收藏和 NAS 记录、三万条队列勾选取消及只读状态取消。使用独立测试资料，没有取消用户正在使用的任务。

退出旧版后覆盖安装即可，不用卸载、清空资料或重新部署 NAS。安装后已有队列继续保留，由用户选择暂停、继续或取消。
