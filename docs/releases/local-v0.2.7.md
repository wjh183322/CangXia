# 藏匣本地版 0.2.7（预览）

新增退出登录、读取期间的强制操作锁与进度弹窗、安全文件续传，并精简登录窗口。

## 退出登录

点击右上角账号，可选择“退出登录”。清除藏匣自己的登录凭据、扫码会话和专用浏览器登录目录，保留原账号绑定、收藏记录、标签、媒体文件和读取进度。本版仍只支持原账号重新登录，不新增多账号资料库。

读取期间禁止退出登录。下载进行中会先提示“暂停任务并退出登录”，确认后等待下载停止、进度保存，再清理登录；重新登录后手动继续。普通 Chrome / Edge 的个人配置与独立抖音程序不在清理范围。

## 读取弹窗

- 开始读取后立即遮罩锁定界面，只保留“停止读取”。Esc、点击空白处及关闭软件不会中断读取，最小化正常可用。
- 界面与后端同时限制其他操作，避免读取中修改资料、下载或切换登录导致冲突。
- 部分读取按“本次新增 / 目标新增数”显示百分比，另列已检查数量，已有记录不计入新增目标。
- 全部读取没有可靠总数时显示动态等待条、真实累计数量和用时，不用平台标称收藏总数伪造百分比。
- 用时每秒刷新，数量仅在收到真实结果后增加。点击停止后显示保存状态，结束后才恢复其他操作；已读内容保留。

## 文件续传与完整性

同一资源地址、强 ETag、已知长度和正确 HTTP 区间响应满足时，使用 `Range` / `If-Range` 继续下载。每个检查点记录 SHA-256，数据落盘同步后再原子更新检查点；恢复时校验已有片段并丢弃未提交尾部。完成后对文件回读计算 SHA-256，确认与接收的字节一致才登记为完成。

资源地址刷新、文件标识变化、区间不符、弱 ETag 或不支持安全续传时，重新下载该未完成文件，已登记且完整的文件不重复下载。断电后可能从稍早的检查点恢复；不保证所有媒体服务器都支持字节续传。源文件本身的内容质量不在传输校验范围内。

实现依据：[HTTP 条件范围请求](https://www.rfc-editor.org/rfc/rfc9110.html#name-if-range)。没有跳过平台限流或登录验证。

## 登录界面

正常扫码只显示二维码、刷新和折叠的“登录遇到问题？”入口。手机尚未确认时显示等待提示；已确认后显示正在连接，不再催促重复确认。

需要短信或身份验证时仍自动显示小验证面板，完成后自动继续。只有较长时间未识别完成时才出现“已完成？重新检查”。完整验证页和专用浏览器作为故障处理入口保留，不再同时堆在普通扫码界面中。

## 使用与验证

退出旧版后运行 `CangXia-Local-0.2.7-Windows-x64.exe`，无需清空原资料或下载目录。左上角与设置版本号同步更新。

测试覆盖片段损坏、资源变化、错误区间、服务器忽略 Range、真实本机 HTTP 连接中断后的续传、认证清理与晚到回调、读取锁与窗口关闭拦截、停止后数据保留、下载暂停后退出、扫码和验证码面板回归。全部使用独立测试目录和合成数据，不访问真实短信验证码。NAS 版与备份版保持独立。
