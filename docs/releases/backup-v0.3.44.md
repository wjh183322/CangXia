# 藏匣备份版 0.3.44

调整 NAS 收藏排序，增加本机保存目录的手动容量统计，并恢复本地媒体库与账号收藏一致的筛选栏。NAS 服务继续使用 0.2.4，无需升级镜像或重新下载作品。

- NAS 默认列表优先使用已保存的总收藏位置；选择自建收藏夹时使用该夹的顺序。原作品失效不会改变仍保留的收藏位置，作者页面保留作者顺序。历史目录缓存可直接使用已有顺序，不自动重新读取抖音。
- 左下角“本机存储”新增“刷新大小”，扫描当前保存目录内全部实际文件，包括未入库文件、临时片段、作品信息和配乐。结果以 GB 显示，并标注统计时间；刷新前的登记文件估算会明确标识。
- 容量统计可离线使用和停止。读取失败、部分不可读、目录发生替换或中途切换保存目录，不会用不完整结果覆盖上次完整测量；不跟随目录链接统计外部目录。
- 本地媒体库恢复五项筛选。排序控件移到列表上方的分页旁，保留收藏顺序、文件从大到小和从小到大；作品大小排序仍按登记文件口径，与整个目录的容量统计分别说明。
- 小窗口下压缩侧栏间距，保留刷新大小、存储设置及读取日志的可见性。

统计的是目录文件大小之和，仅读取文件属性，不下载作品或修改文件内容。后台下载期间目录仍可能变化，统计时间用于说明结果的新旧程度；需要最新结果时可再次刷新。

原因、边界与复核见[开发验证记录](../research/2026-10-21-nas-order-and-local-directory-size.md)，测试及安装包校验值见[本机验收](backup-v0.3.44-verification.json)。云端 CI 状态单独报告。
