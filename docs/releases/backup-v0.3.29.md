# 藏匣备份版 0.3.29

修复图文浏览时配乐控件覆盖图片底部的问题。播放器移到图片区域下方的独立栏，由窗口布局为它保留位置；图片按剩余空间等比例完整显示，保留原始像素，不裁切、不覆盖。原有播放、静音、切图、换作品和视频互斥行为保留。

修复封面已经在本机正常显示，但自动备份仍反复访问失效地址、一直显示封面待备份的问题。备份和定向补齐优先复用已校验的封面缓存索引，同时兼容旧的作品 ID 缓存。无有效缓存时，主封面地址失败会尝试同一作品已保存的其他封面地址，最多六个；遇到 HTTP 429 停止当前尝试。损坏缓存不作为成功文件上传。

不会重新读取整批作品，也不降低图片质量。仍沿用原有分批准备、容量限制、同库提交回执及待确认保护：封面只有在 NAS 确认后才标为已备份。所有地址失效、网络不可用或预算不足时仍保留待备份状态，需要后续重试或定向补齐。

回归验证覆盖哈希浏览缓存复用、失效主地址备用来源、损坏缓存排除、平台限流停止、定向补齐复用缓存。真实 Chromium 对 1400×960、1280×874、1100×640 三种窗口及竖图、横图、长图共九种组合核对几何范围，确认播放器与图片和底部说明不相交，静音未请求配乐。

退出旧程序后覆盖安装即可，保留现有记录、下载任务、媒体、登录和 NAS 配置，无需删除缓存或重新读取。NAS 服务仍使用 0.2.3；已升级者不用再升级，尚未升级者需要先更新 NAS 服务才能使用共享配乐备份。
