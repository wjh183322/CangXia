# 藏匣备份版 0.3.7

修复 0.3.6 下载前串行刷新资源造成的实际传输不足，以及登录不可用时连续弹出作品浏览器页面。

普通下载现在优先使用资料库中已保存的媒体地址，可直接并行传输。仅在资源缺失或返回 401、403、404、410 时，按作品后台刷新一次后补齐；已成功保存的文件保留。后台下载禁止退回打开公开作品页面，登录需要更新时暂停队列并提示重新连接，不会连续弹出浏览器。手动导入作品链接和主动打开原作品仍保留原功能。

下载管理分别显示“正在传输”和“准备 / 等待”数量；等待后台查询不再标作正在下载。并发数仍为 1 至 6，默认 3。

NAS 使用权：按设备标识区分本机旧会话与其他电脑；同名但不同标识的实例不会直接接管。锁未过期时自动重查，提示剩余时间。续期请求合并，释放锁前等待正在进行的续期结束；关闭时先停止定时续期，避免释放和续期重叠。服务端原有 90 秒租约机制继续保留，不跳过写入保护，不改动 NAS 协议。

验证：255 项自动测试、50 项界面检查和 26 项桌面集成检查通过。新增六路本地 HTTP 文件同时传输及断点恢复、失效资源单次后台刷新、无登录时暂停且不打开公开页面、本机旧锁过期后恢复、并发续期与释放等检查。桌面集成使用模拟媒体响应验证六个作品同时传输、且已有地址不触发详情查询；未对用户真实抖音下载队列进行带宽测速。

升级：暂停下载并等待任务停止，完全退出旧版后覆盖安装。保留现有资料、下载文件和下载队列，不删除缓存。若提示重新连接抖音账号，连接后再继续下载。NAS 服务无需更新；旧实例已退出但锁残留时，等待约 90 秒后重新检查即可。
