# 藏匣备份版 0.3.42

修复完整作品仍被列入问题总览、Windows 预览占用导致删除失败，以及平台隐私限制响应漏判的问题。NAS 服务继续使用 0.2.4，无需升级镜像。

- 已确认本地文件完整、没有其他缺损或失败任务的作品退出“问题总览”，原作品失效提示仍在正常列表和详情中保留。本轮结果历史也保留；旧问题索引会更新，无需自动重扫全库。
- 删除本机作品前释放所选作品的预览文件句柄，避免需要关闭藏匣才能删除。独立删除本机配乐也释放对应音频句柄，其他作品及同作品封面继续可读。
- 删除失败时显示具体原因。NAS 已成功、本机失败时保留处理回执，重试仅处理未完成步骤。确认删除时提示所选副本范围和原作品不可观看时的恢复风险。
- 支持实际提供的 `status_part_see` 隐私限制响应。根据已验证的明确平台说明与对应作品 ID 判断当前不可观看；登录、验证、限流、网络错误和矛盾数据仍保持暂无法确认。继续仅使用 JSON，不使用网页复核。

更新后可以重新核对此前暂无法确认的作品。不会因更新删除文件、读取记录或 NAS 备份，也不会自动重试历史失败任务。

原因、复现及验证边界见[调查记录](../research/2026-10-21-complete-works-and-preview-deletion.md)，完整验证及实际安装包校验值见[本机验收](backup-v0.3.42-verification.json)。Windows 文件句柄复现使用隔离测试目录，未操作用户实际目录或修改权限。

本机完整套件 673 项通过，零失败、零跳过；界面 169 项、状态专项 73 项、打包桌面 77 项通过。源码与打包后的 JSON 浏览器检查各 26 项，真实 Windows 预览句柄专项各 11 项。两个实际分发 EXE 已分别解包、核对相同 ASAR，并在隔离空资料目录启动成功。云端 CI 结果单独报告。
