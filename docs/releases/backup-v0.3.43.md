# 藏匣备份版 0.3.43

增加已添加自建收藏夹的一次批量同步。账号收藏侧栏的“自建收藏夹”旁提供“同步全部”，默认检查新增，也可以选择完整核对。NAS 服务继续使用 0.2.4，无需升级镜像。

- 只依次读取藏匣已添加的自建收藏夹，不读取总收藏、不自动添加其他夹、不自动下载作品。同名收藏夹按 ID 分别处理。
- 没有可靠历史对照的收藏夹在开始前统一提示，明确确认后才允许检查到列表末尾。完整核对需要主动选择。
- 显示当前收藏夹、已处理数量及当前夹作品进度。支持停止，已读取内容和各夹检查点保留，未完成读取可进入对应收藏夹继续。
- 每个收藏夹保留独立读取日志。结果页列出完成、失败、跳过及未处理内容；单夹失败记录原因后继续，登录失效、限流或保存失败停止后续读取。
- 已知无法读取的历史收藏夹跳过，已有记录和文件保留。历史作品本轮未返回也不会自动删除。

同时补齐同步准备阶段的停止检查：在音频暂停或 NAS 收尾等待期间点击停止，准备结束后也不会重新开始读取。

设计、复现与验证边界见[批量同步记录](../research/2026-10-21-added-collection-batch-sync.md)，本机测试和安装包校验值见[版本验收](backup-v0.3.43-verification.json)。云端 CI 结果单独报告。

本机完整套件 691 项通过，零失败、零跳过；读取专项 39 项（含新增批量回归 18 项）、界面检查 179 项通过。源码和打包桌面集成各 85 项通过，包含准备阶段停止和小窗口进度；源码及打包 JSON 浏览器检查各 26 项，后台读取 16 项、打包预览句柄检查 11 项通过。两个实际 EXE 已分别解包、核对相同 ASAR 并在隔离资料目录启动成功。
