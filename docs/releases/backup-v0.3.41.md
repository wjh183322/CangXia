# 藏匣备份版 0.3.41

修复两种平台已明确返回不可访问、但 0.3.40 仍显示“暂无法确认”的作品状态。继续仅使用 JSON 核验，不恢复作品网页复核；NAS 服务继续使用 0.2.4。

- 支持用户提供的 `status_friend_see` 隐私限制响应：作品 `7689008683628901478`，平台明确提示“由于对方隐私设置，无法查看”。
- 支持用户提供的 `status_deleted` 不可观看响应：作品 `7684245301557820859`，平台明确提示“因作品权限或已被删除，无法观看”。
- 仍要求成功业务码、精确作品 ID、明确空详情及对应的已验证文字；登录、验证、限流、错误 ID 和矛盾响应保持暂无法确认，不扩大为任意原因码均判失效。
- 原作品状态与本地文件状态独立：本地文件已保存的失效作品可以同时显示“无文件问题”和“原作品已失效”。保留读取记录、本机文件和 NAS 备份；恢复访问后仍由用户手动重试下载。

更新后对之前暂无法确认的作品重新核对状态即可，不需要清空资料、缓存或重读整个资料库。程序不会因更新而自动扫描全部作品。

原因与验证范围见[调查记录](../research/2026-10-21-source-access-filter-fix.md)。

本机完整套件 652 项通过、零失败、零跳过；状态专项 67 项，源码与打包后的 JSON 浏览器测试各 23 项，后台读取 16 项、打包桌面集成 76 项通过。两种实际 EXE 已分别解包，核对相同 ASAR 后在隔离空资料目录启动成功。校验值见[本机验收](backup-v0.3.41-verification.json)，不把本机及合成测试表述为真实用户账号验收。
