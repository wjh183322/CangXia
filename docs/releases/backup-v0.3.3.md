# 藏匣备份版 0.3.3：定向补齐失败作品

右上角新增“补齐失败”。先扫描本机资料库，列出封面异常、封面尚未成功备份、已保存文件缺失或大小异常、下载失败及部分无法检查的项目。扫描不请求抖音收藏分页，不把未下载的普通作品认定为缺损媒体。

勾选问题作品后点击“补齐选中”。只有这些作品会执行刷新、取回封面或安排缺失文件下载，收藏关系和顺序保留。封面可以从 NAS 或已校验的本机缓存恢复；需要新地址时，只刷新这一条作品详情。收到不匹配作品 ID 的响应会拒绝写入。

失败列表提供作品名称、作者、ID、原因和原作品入口，可按封面、文件、无法检查筛选，并支持分页。结果显示当前进度、成功、失败与交给下载管理的数量；图片和视频文件由既有下载管理执行，入队不等于已经下载成功。

支持停止、继续未完成及重试失败项。任务状态使用本机独立 SQLite 保存，重启可继续；不上传 NAS，不保存登录密钥。账号发生变化时拒绝旧任务续接。已有成功项目不会随着“继续”全部重做。

一个来源失效不会阻止其他作品；平台要求验证、限流时暂停剩余任务，完成验证后手动继续。文件目录不可访问时只列出原因，不擅自重建目录或覆盖文件。源图持续 404、作品不可访问等情况会保留失败原因，不能保证每次重试都能恢复资源。

正在补齐期间暂停 NAS 备份，完成后空闲同步；NAS 断联时当前封面刷新仍可保存本机，但不会在 NAS 不可写时启动新的媒体下载任务。刷新只有缺陷作品，不从头核对两万多条收藏。

## 验证

已通过 244 项自动化测试，其中 10 项新增定向补齐回归覆盖单条刷新、只补已请求媒体、顺序保留、404 后继续其他项目、停止续接、重启恢复、账号变化拒绝续接、限流暂停和 NAS 断联行为。44 项界面检查通过，覆盖选择一条补齐、进度与停止；24 项真实 Electron 桌面检查通过，含实际 IPC 缺陷扫描和新弹窗。新弹窗已截图检查，打包程序启动与源文件一致性在交付时复核。

升级客户端即可，NAS 服务仍为 0.2.0、协议 2。保留已有资料和封面缓存，不需要重新读取收藏或重新部署 NAS。
