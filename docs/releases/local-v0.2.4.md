# 藏匣本地版 0.2.4（预览）

短信身份验证现在使用小窗口，只展示可识别的官方验证面板，不再默认把整个抖音网页和侧栏嵌进软件。

- 正常扫码仍使用原来的二维码小窗口。
- 真正需要身份验证时，定位官方验证卡片，通过原生视图裁切显示，保留原网页的控件、会话及输入状态。
- 不重建验证码表单，不读取输入值，不自动发送短信。验证仍由抖音官方页面处理。
- 面板未能识别或页面布局改变时，隐藏裁切区域，提供“打开完整验证页”入口；使用原来的页面，不重新登录。
- 左上角和设置中的版本号统一为 0.2.4。

退出旧本地版，运行 `CangXia-Local-0.2.4-Windows-x64.exe`。保留原资料和下载目录，无需清空缓存。

验证使用合成页面与独立资料目录，覆盖面板定位、二维码不误展开、紧凑窗口、原生裁切边界、未知页面隐藏、完整页切换、输入状态保持及关闭清理。实际平台页面仍可能变化，保留完整验证页作为备用入口。本版不修改收藏请求方式、NAS 版、备份版或 NAS 服务。
