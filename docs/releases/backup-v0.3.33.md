# 藏匣备份版 0.3.33

修复原作品核验漏读 `filter_detail`：当作品详情为空，但平台针对同一作品 ID 返回已核实的 `status_self_see`、作品不见了提示和“因作品权限或已被删除，无法观看”说明时，归入“已失效”，原因显示“权限限制或已删除，当前无法观看”及平台原提示。`status_code: 0` 仅代表接口请求处理成功，不代表作品可观看；此类返回也不被解释为确定已删除。

手动单条核验、批量核验和普通下载刷新资源使用同一判定。已失效的未完成普通任务退出下载失败列表与自动补齐；其他作品继续。已下载文件、已完成任务、收藏顺序和 NAS 副本保留。只返回空详情、作品 ID 不匹配、未识别的过滤原因、登录/验证码或其他含糊提示时仍保持“无法确认”。普通列表刷新不清除已失效标记，主动核验取得对应作品和可用资源后才恢复可访问。

验证使用用户提供的两次真实响应结构做离线回归，并覆盖下载任务、保存文件和状态恢复；原生桌面与打包程序验收使用同结构的隔离响应，检查原因展示与文件保留，不声称已在遵义账号现场重跑。

退出旧程序后覆盖安装，无需清缓存、删除数据或重新读取全部收藏。此前显示“无法确认”的作品需要再次核验原作品状态，可单条核验或在“作品检查与补齐”中批量核验。NAS 服务没有改动，继续使用 0.2.3。
