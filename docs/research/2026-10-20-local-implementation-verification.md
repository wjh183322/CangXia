# 本机下载与问题总览实施验收

对应计划：`docs/superpowers/plans/2026-10-20-local-download-and-problem-overview.md`。本机版本 0.3.35，NAS 服务版本仍为 0.2.3。NAS 跨电脑删除和独立恢复按另一份已批准计划继续，不在本次桌面补丁中启用。

## 已验证的行为

- 必需资产已登记且文件身份、普通文件类型、路径归属和字节数通过核实后，部分完成状态可原子更新为完成；重复重试不新增网络请求。
- 同名旧视频没有登记依据时不直接认定完成。旧文件保留，新下载另取安全文件名，确认后登记；同时保护下载期间新出现的同名文件。
- 问题总览独立于本轮任务持久保存。源状态、文件状态和任务状态分别更新，局部核验、停止、任务历史清理不会抹去其他未解决项。
- 面板打开只读取已保存总览。手动检查全部或选中项才扫描文件；分页每页 20，分类数量可交叉，总数按作品去重。
- 下载列表和检查两个标签的标题按作品 ID 打开本地详情；队列继续运行，关闭详情后回原标签、分页、筛选、滚动和有效选择。过期全选不扩展范围。
- 本地媒体库按索引字节数稳定排序，未知大小最后；不因排序扫描硬盘。普通文件字节与完整度分别判断，共享配乐、缓存和未登记文件不计入作品正式文件大小。
- 已提供的空文字 `status_audit_self_see` 响应只在成功响应、目标 ID 匹配、明确空详情且无验证/限流证据时判当前不可访问；不推断具体删除原因。

## 实施取舍

1. 自动工作树创建失败后使用专用分支，测试隔离、逐文件暂存；没有切换或清理用户目录。
2. 保留原文件确认布尔接口，通过每次调用的结果回调返回具体原因，避免全局错误状态串到另一作品。
3. 文件发布采用独占方式；不支持硬链接时使用独占复制，禁止覆盖过程中出现的其他文件。
4. 沿用同作品可信资源缓存和失败后刷新流程，未登记旧文件不凭名字复用；失效缓存地址可能先失败一次。
5. 工作线程结果绑定清单签名和存储根目录，变化后不套用旧检查结果。
6. 详情返回只恢复仍有效选择；全选快照过期时提示重新选择，避免多选到未确认作品。
7. 字节数反映已登记普通文件的实际空间，完整度独立判断；缺失可选高清资产不阻止普通下载完成。
8. 问题缓存绑定本地数据库身份与变更位置；明确换库或回退时重建派生缓存。正常重开保留任务和问题，当前已提交事实不受电脑时钟回退阻挡。

## 实机界限

用户给出的单个 JSON 仅登记封面，截图另有视频及 0 字节 part，不能单靠这些资料证明遵义当前数据库中的下载状态，也不能代表全部 9 条失败作品。合成样本证明已修复的确认循环，遵义实机安装后仍需观察；残留问题可从对应作品导出小范围脱敏诊断，不需要重新读取全库或清缓存。

取消抖音收藏仍为研究项，没有执行线上写入。NAS 删除与恢复尚待配套实现、双客户端测试和服务镜像交付，不能用本机版本代替其验收。
