# 原作品自动状态核验验收

本次桌面版本 0.3.38，配套 NAS 0.2.4，协议和资料库结构未变。目标是自动识别用户提供的隐私限制响应，以及空原因响应对应网页的明确“不存在”提示，同时防止误标正常作品。不删除读取记录、本机完整或部分保存的正式文件，也不删除 NAS 备份。

## 已采用的证据规则

1. 成功响应、相同作品 ID、详情为空，且 `author_secret`、隐私说明和“作品暂时无法查看”三者吻合：确认当前账号不可访问，保留隐私原因，不推断已删除。
2. 成功响应、相同作品 ID、详情明确为空、原因和提示均为空：仅在已绑定登录账号的浏览器请求模式下，进入对应官方作品页自动复核。核验前后检查账号及会话指纹；有变化则丢弃结果。
3. 对应官方作品 URL 上可见的“你要观看的视频不存在”，同时存在官方下一步操作提示，连续两次观测一致，并且没有尚未完成或未读取的对应详情响应，才作为网页失效证据。排除评论、推荐、标题、隐藏文本和其他作品。
4. 对应详情包含媒体资源可确认恢复可访问；登录、安全验证、限流、网络、跳转、失败业务码和异常响应保留未知。`status_code: 0` 只代表接口调用成功，不代表作品失效。

## 运行和资源范围

每次只复核一个作品，默认上限约 10 秒，停止可取消。使用独立隐藏后台页，保留账号读取页，完成或失败后关闭自有临时页。设置正常视口；阻止媒体和图片网络传输，禁用该页 HTTP 缓存和 service worker。只持久保存简短状态原因、核验方式、时间，不保存网页 HTML 或响应全文。现有队列仅退下该失效作品未完成的抖音任务；完成记录和明确选择的 NAS 恢复任务保留。重新确认正常不会自动重启下载。

## 审查与验证边界

独立审查发现两处可能误判的竞争路径：尚未读取的正向详情响应、以及被忽略的访问/传输失败。均先建立失败回归，再修正。细节见同目录 `2026-10-21-automatic-source-verification-review.md`。

真实 Chrome 验证使用自有临时 profile、虚构账号和受控官方来源页面。检查实际 CDP、DOM、网络拦截、取消及临时页清理，但不等于在遵义电脑真实账号上完成在线验收。用户提供的真实响应作为分类样本。站点变化或证据不足仍可能显示暂无法确认，不凭空扩展未知原因码。
