# 客户端响应性优化本地验收

日期：2026-10-28。桌面 0.3.47，NAS 仍为 0.2.4 / 协议 3，无需升级镜像。源码与运行代码为本分支（关键故障修复提交 aebe58e）。全部本地必需检查完成；交付前另核对精确推送提交的 GitHub CI，本记录不将旧提交或运行中结果当成云端通过。

## 改动与效果

下载准备采用一次目录归属索引、异步文件保护快照、事务性受理和分段让出事件循环。大库只读分析使用按需 Electron utility process，完成数据库读快照后才发送需 ACK 的数据。正式写入仍由主进程负责，不向辅助进程传递凭据。

准备可停止、关闭重开和明确继续；中断已受理任务保持 held，重试保留原 epoch。完成摘要与放行门控同事务，提交后才调度。持续保存失败可见，继续初始化失败不遗留运行锁；相交删除范围拒绝重新受理，停止会中止同次调用的后续来源分组。

浏览进度更新不再重建整个轻量资料库，搜索与大小排序均取消过期请求。新增计数、来源、收藏顺序与 NAS 删除/恢复规则不变。

先前与全量测试并行的非最终对照曾出现 765/401 ms 长停顿。增加同步阶段和 GC 测量后独立重复，未复现；未能确定那两次的根因，保留原报告，未归因为环境偶发。SQLite 同步提交仍受实际磁盘/系统延迟影响。
