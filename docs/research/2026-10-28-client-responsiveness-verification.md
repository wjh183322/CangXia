# 客户端响应性优化验证记录

日期：2026-10-28。版本：桌面 0.3.47；NAS 服务仍为既有 0.2.4 / 协议 3。

状态：候选实现已完成，最终全量、安装包与独立整分支审查进行中。本文件的“待复核”不能当作通过。

## 已实现的范围

- 下载准备复用目录归属索引、任务 ID 索引和分段受理；大库目录分析使用独立 Electron utility process。
- 首次任务文件保护快照使用异步读取；暂停、失败重试沿用原 epoch，取消清理仍保留任务之前的文件及独立替换内容。
- 批次意图、受理快照、结果与调度门控持久化；完成摘要与放行标记同事务提交，提交后才启动下载。
- 单项失败可继续其他项；整批中断和重启保留已受理任务为暂停；暂停、取消和明确继续分别处理。
- 数据更新与运行进度分开，避免纯进度保存重建整个轻量资料库；筛选合并请求并取消过期查询。
- 移除本机文件记录时同时失效轻量索引、持久化文件证明和未保存筛选；不删除 NAS 备份或读取记录。
- 状态保存失败会通知界面；维护失败单独提示。元数据保护原文不截断：单文件 16 MiB、单批保护资料 64 MiB，超限明确失败或暂停而保留文件。

## 同机性能基准

基线固定为 `08e6436522a3828211e9c32b51f90d7d830b4fa8` 的源码，通过归档提取运行，不能从修改后的 enqueue 推测旧行为。

夹具为真实临时 SQLite、31,542 条已保存清单和 775 个新任务；清单每条四个资源，保存状态和媒体来源为模拟，测试不联网、不下载媒体、不访问真实用户库。

原版三轮冷路径：122,947.9 / 123,093.7 / 126,339.5 ms，中位数 123,093.7 ms。每轮均实际解析 24,445,050 条清单，775 次全清单读取。

原子放行最终调整之前的优化三轮冷路径：5,223.9 / 3,853.5 / 3,007.0 ms，中位数 3,853.5 ms；热进程约 2.7 秒。重复全清单读取为零。最终代码的新测量待复核，不直接复用此数字作最终承诺。

基准输出包含各轮首心跳、事件循环 p95/max、主进程 RSS/高水位及辅助进程资源。高水位为进程生命周期（含夹具准备），不能声称是纯操作内存或把不同进程非同时峰值当成实测总峰值。

## 桌面与故障证据

- 原子放行最终调整前：Node 全量 788/788；源码桌面 104 项；界面 232 项；四种布局通过；独立 NAS 预览 31 项。
- 源码及 ASAR 大库窗口夹具均实际受理 775 项、目录索引一次；准备期间可翻页和搜索，1100×640 的停止按钮可见，正常退出等待准备停止。此前首状态约 110/125 ms，p95 约 18–23 ms。夹具含人工 2 ms I/O 延迟及模拟 NAS 状态，不是遵义电脑/NAS 实测。
- 已完成 RED→GREEN：回滚不能虚报已受理；正在运行队列游标不能漏掉新放行任务；继续前后复核保存根目录；放行失败保留门控；完成摘要失败不能先启动下载；回滚不吞掉其他任务脏状态；持续状态保存失败仍发布错误；取消部分已受理项更新继续数量。
- 巨大元数据、超预算、辅助进程目录回复不匹配、源库切换、共享搜索初始化关闭均有隔离回归。
- 曾有一次取消回归保留了大小写异常的元数据临时文件；随后单独、组合及全量均未复现。保留了归属/文件事实诊断，不把它归因为环境偶发，也未放宽独立替换文件保护。

## 验证中发现的工具/夹具问题

1. 桌面布局检查曾因隐藏窗口不产生动画帧而超时。记录到 `document.visibilityState=hidden`、`visible=false`；为布局等待增加 300 ms 兜底后，仍执行实际几何断言并通过 104 项桌面检查。读取日志检查也须先等待前台读取提示结束再模拟用户导航。
2. 原合并打包命令的 7-Zip 曾返回内部错误。同二进制、同输入及压缩参数的独立压缩成功，顺序构建 NSIS 与 portable 也成功；初次失败的确定根因尚未查明，不能称其为已修复的硬件问题。最终产物需重新验证解压、ASAR 与实际启动。
