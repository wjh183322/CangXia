# 藏匣：已确认需求

Windows 桌面软件，账号收藏与已保存媒体库分开。支持本机库及可选 NAS 库；NAS 模式共享媒体和作品记录，登录凭据留在各自电脑。不依赖第三方解析商。

NAS 模式用于交替使用电脑，同一时刻一个写入者，其他客户端只读；断网不视为作品或文件删除。迁移采用复制校验并保留本机原件，详细使用方式见 v0.1.8 版本说明。独立备份延期至新增硬盘后配置。

## 收藏与目录

- 两侧均为封面墙；账号收藏保留抖音网页返回的顺序，不能按作品发布时间代替收藏顺序。
- 总收藏包含所有收藏作品。除总收藏外，一条作品最多归属一个自建收藏夹。
- 初次仅添加总收藏。发现账号收藏夹后，用户选择添加；已添加夹持久保存且不重复提示。
- 磁盘：`下载根目录/自建收藏夹/标题-作者/`。未归入已添加自建夹的作品存入 `收藏/标题-作者/`。
- 加入、改名、移动已添加收藏夹后，主动同步会调整本地目录；取消收藏、删除远端收藏夹、作品失效均保留本地文件。
- 软件本地总收藏仍显示所有本地作品，作品在自建夹中也可见，磁盘只保存一份。
- 同名、Windows 不允许的字符、过长名称由安全命名规则处理；必要时追加作品 ID 消歧。

## 保存与筛选

- 视频保存视频、对应高清单图、作品信息；图文保存原图与作品信息。
- 单图优先来自作品提供的原始封面资源；不能默默用抽帧冒充原图。用户指定样例需对照存图宝单图验收。
- 保留作品 ID、原始标题/作品名、完整文案、原始话题标签、作者昵称、抖音号、内部 UID/sec_uid、收藏夹关系及保存时间。
- 原始标签与本地自建标签分开，支持任意/全部标签匹配、作者和作品类型筛选。
- 支持单选、当前页视频全选、当前列表跨页全选。
- 重复下载跳过有效文件，补齐缺失资产；部分完成不标为全部已下载。
- 账号列表中的已下载标记来自真实本地资产；手动删除或外部删除后更新。
- 本地手动删除需确认。原作品已失效时强调无法从原作品重新下载。
- 只有可靠的详情结果明确表明作品已删除/不可用才标失效；登录过期、网络异常、未在本轮收藏列表中出现不构成失效依据。

## 读取方式及验证边界

通过隔离的抖音浏览窗口正常登录、读取网页自身的网络响应。无需用户复制 Cookie，不自行生成签名，不绕过登录、验证码和访问限制。接口字段或页面变化时明确报告读取不完整，不用空结果覆盖已有完整快照。

验收样例：https://www.douyin.com/video/7683829929179724518 （苏苏鸭，#fgo #黑枪呆 #剪映）。正常浏览器已验证可播放，但最高画质与存图宝高清单图仍需核对。个人总收藏、收藏夹目录与完整分页必须在用户登录后验收。
