Windows 本地抖音收藏管理工具。账号收藏与本地媒体库独立，按自建收藏夹存放媒体文件，保持总收藏和自建收藏夹的逻辑关系。

当前版本包含读取记录删除、每页 20 个、统一弹窗和补齐前检查，并修复筛选及本地封面墙缩小的问题。

## 运行

打开 `release/CangXia-0.1.7-Windows-x64.exe`。这是免安装程序，需要 Windows 10/11 64 位。程序数据保存在 `%APPDATA%/藏匣`，媒体默认保存在 Windows 下载目录下的 `藏匣` 文件夹；首次下载前可在右上角齿轮“设置”中选择其他目录；已有下载作品后锁定目录。

## 第一次使用

1. 点击“连接抖音账号”，在软件自己的扫码弹窗中，用手机抖音扫一扫。登录成功后自动连接并收起弹窗。正常扫码不需要导入 JSON。
2. 选中要读取的收藏范围，点击“同步收藏”，填写最大新增数量（默认 20），选择部分读取或全部读取。读取只更新列表，不会自动下载。
3. 点击左侧“添加收藏夹”→“读取账号里的收藏夹”，选中要添加的夹。已添加项会保留。
4. 选中某个自建收藏夹后同步，仅读取该夹。已有作品不占新增名额，但仍更新信息和归属，不额外核对其他夹。
5. 单独勾选作品、全选当前列表所有页，或者选择当前页全部视频，点击“下载所选作品”。
6. 本地封面单击浏览、双击详情；左右切换图片和视频，上下跨页切换作品。启动默认静音，本次运行共享音量。标签与我的标签独立筛选，已有我的标签可快速勾选标注。

单个作品也可通过“作品链接”预览和下载。该操作不会自动把作品加入账号收藏。

## 文件规则

```text
下载目录/
  收藏/
    标题-作者/
      视频.mp4
      单图.jpg
      作品信息.json
  自建收藏夹/
    标题-作者/
      ...
```

作品只保存一份：归属于已添加自建夹时放在夹内，否则放在“收藏”。软件本地总收藏仍展示全部本地作品。同步时跟随收藏夹改名及作品移动；取消收藏、源作品失效、远端删除收藏夹均保留本地文件。同名目录会追加作品 ID，防止覆盖。

重复下载补齐缺失文件。“已下载”依实际文件状态判定；外部删除文件后，可点击“刷新文件状态”。软件删除会弹出确认并把作品文件夹移入 Windows 回收站，同时撤销已下载标记。失效作品会额外提示无法从原来源重新下载。

原始标签和本地标签分别保留。作品信息中保存作者昵称、抖音号、内部 UID/sec_uid，避免仅凭昵称关联。

- 已通过文件归属、目录移动、保留归档、去重补齐、真实文件状态与标签筛选测试，以及 Windows 桌面启动测试。
- 已实测用户提供的作品 `7683829929179724518`：视频下载成功，浏览器解码为 **1080×1920，7.166667 秒**；作者标识与 `fgo / 黑枪呆 / 剪映` 标签提取成功。
- 此样例的原始静态封面仅 **360×640**。程序保存实际提供的图片，并在详情里显示真实尺寸及清晰度提示。**尚未验证它与存图宝“高清单图”一致，也没有声称取得该样例的更高清单图。**
- 个人账号收藏列表、收藏夹目录与所有分页，需要用户登录后做真实账号验收。网络响应结构和网页布局可能变化；程序不会把验证码、登录过期、空响应或读取中断当作完整空收藏。
- 视频选择网页实际返回的播放源，不进行视频画面水印擦除。作者写入画面的内容会保留。
- 当前只针对一个抖音账号。已有作品后不支持一键迁移整个媒体库根目录。

## 开发

```powershell
npm install
# 如果 npm 未执行 Electron 的安装脚本：
node node_modules/electron/install.js
npm run dev
npm test
npm run dist
```

技术栈：Electron、React、Vite、SQL.js（SQLite）。主登录方式为应用内扫码弹窗，后台使用隔离的正常网页登录会话；需要验证时在应用内打开验证窗口。导入的登录信息由 Windows 加密保存在本机。媒体及元数据只写入用户选择的目录，不使用第三方解析服务器。

开发服务器仅监听 `127.0.0.1`。`?fixture=1` 是仅开发模式可用的明确标记测试数据，不进入发布版本。

需求细节见 `docs/需求与验收.md`。

## 0.1.1 登录修正

- 登录请使用标题为“藏匣 · 抖音网页登录（本机独立会话）”的窗口。官方抖音客户端登录状态不共用。
- 登录阶段不连接采集调试器；检测到本机网页登录状态后，才允许同步收藏。
- 取消作品解析超时后的自动刷新，避免打断扫码。
- 检测到访问过于频繁或 HTTP 429 时暂停读取和下载，至少退避60秒，不自动重试。这是程序的最短等待时间，并非平台承诺的恢复时间。
- 修正不代表平台当前的登录限制已解除；不要反复扫码刷新。如仍受限，需要在正常浏览器对照检查登录是否可用。

## 0.1.2 系统浏览器与配置导入

已根据参考项目接入系统 Chrome/Edge 登录和本机配置导入，支持下载前视频预览。图片将比较实际像素并显示来源，仍不承诺取得所有作品的高清原文件。详细分析见 [参考项目核查](docs/参考项目核查.md)，相关 MIT 许可证已随程序保留。

## 0.1.5 软件内扫码弹窗

参考 legacy v0.2.7 改为二维码弹窗，默认不打开完整浏览器，扫码后自动连接。已验证真实二维码可取得，后台页保持隐藏；实际用户登录仍需扫码确认。

JSON 导入只是复用参考工具 config.json 中的登录会话，不导入收藏列表或媒体文件。入口移至“存储设置 → 高级”，普通扫码用户无需使用。
