# 藏匣 CangXia

当前版本：**v0.1.1** · Windows 10/11 64位 · 分支 `main`

[下载 v0.1.1](https://github.com/wjh183322/CangXia/releases/tag/v0.1.1) · [历史 v0.1.0](https://github.com/wjh183322/CangXia/releases/tag/v0.1.0) · [变更记录](CHANGELOG.md)


Windows 本地抖音收藏管理工具。账号收藏与本地媒体库独立，按自建收藏夹存放媒体文件，保持总收藏和自建收藏夹的逻辑关系。

## 运行

打开 `release/CangXia-0.1.1-Windows-x64.exe`。这是免安装程序，需要 Windows 10/11 64 位。程序数据保存在 `%APPDATA%/藏匣`，媒体默认保存在 Windows 下载目录下的 `藏匣` 文件夹；首次下载前可在“存储设置”选择其他目录。

## 第一次使用

1. 点击“连接抖音账号”，在独立的抖音窗口里正常扫码登录。
2. 返回藏匣，点击“同步收藏”。读取时保留抖音窗口，由程序按正常网页翻页。
3. 点击左侧“添加收藏夹”→“读取账号里的收藏夹”，选中要添加的夹。已添加项会保留。
4. 再次同步，读取已添加收藏夹中的作品。某夹不能自动打开时，在抖音窗口里打开对应夹，再重试；读取未完成会明确提示。
5. 单独勾选作品、全选当前列表所有页，或者选择当前页全部视频，点击“下载所选作品”。
6. 在“本地媒体库”播放视频、浏览图片、添加自建标签，按标签/作者/类型筛选。

单个作品也可通过“作品链接”预览和下载。该操作不会自动把作品加入账号收藏。

## 文件规则

```text
下载目录/
  收藏/
    标题-作者/
      视频.mp4
      单图.jpg
      作品信息.json
  自建收藏夹/
    标题-作者/
      ...
```

作品只保存一份：归属于已添加自建夹时放在夹内，否则放在“收藏”。软件本地总收藏仍展示全部本地作品。同步时跟随收藏夹改名及作品移动；取消收藏、源作品失效、远端删除收藏夹均保留本地文件。同名目录会追加作品 ID，防止覆盖。

重复下载补齐缺失文件。“已下载”依实际文件状态判定；外部删除文件后，可点击“刷新文件状态”。软件删除会弹出确认并把作品文件夹移入 Windows 回收站，同时撤销已下载标记。失效作品会额外提示无法从原来源重新下载。

原始标签和本地标签分别保留。作品信息中保存作者昵称、抖音号、内部 UID/sec_uid，避免仅凭昵称关联。

## 开发

```powershell
npm install
# 如果 npm 未执行 Electron 的安装脚本：
node node_modules/electron/install.js
npm run dev
npm test
npm run dist
```

技术栈：Electron、React、Vite、SQL.js（SQLite）。远程抖音窗口开启沙箱与上下文隔离，没有本地文件访问桥；登录会话留在本机。媒体及元数据只写入用户选择的目录，不使用第三方解析服务器。

开发服务器仅监听 `127.0.0.1`。`?fixture=1` 是仅开发模式可用的明确标记测试数据，不进入发布版本。

需求细节见 `docs/需求与验收.md`。

## 0.1.1 登录修正

- 登录请使用标题为“藏匣 · 抖音网页登录（本机独立会话）”的窗口。官方抖音客户端登录状态不共用。
- 登录阶段不连接采集调试器；检测到本机网页登录状态后，才允许同步收藏。
- 取消作品解析超时后的自动刷新，避免打断扫码。
- 检测到访问过于频繁或 HTTP 429 时暂停读取和下载，至少退避60秒，不自动重试。这是程序的最短等待时间，并非平台承诺的恢复时间。
- 修正不代表平台当前的登录限制已解除；不要反复扫码刷新。如仍受限，需要在正常浏览器对照检查登录是否可用。
